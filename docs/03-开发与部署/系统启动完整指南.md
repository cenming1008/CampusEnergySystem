```bash
docker exec campus_energy_db_dev psql -U admin -d campus_energy -c "
SELECT 
    energy_type, 
    COUNT(*) as records,
    MAX(timestamp) as latest_time 
FROM energydata
```

## 🔧 故障排查

### Backend 无法连接数据库
```bash
# 检查 Docker 服务
docker-compose -f docker-compose.dev.yml ps

# 检查数据库
docker exec campus_energy_db_dev pg_isready -U admin
```

### 模拟器没有数据
```bash
# 检查模拟器是否运行
ps aux | grep simulator

# 查看模拟器日志
cat /tmp/sim_output.log

# 重新启动
python scripts/python/simulator_unified.py
```

### 数据没有写入数据库
```bash
# 检查 Backend 日志
tail -f logs/app.log | grep MQTT

# 检查 MQTT 服务
docker logs campus_mqtt_dev
```
