# MQTT 端口防火墙策略

## 推荐策略

- `1883/tcp` 只允许矿区网关、采集器或专用接入网段访问
- `9001/tcp` 仅在确实需要 MQTT over WebSocket 时开放，否则关闭
- 管理面板、数据库、Redis 不与 MQTT 端口共用公网暴露策略

## 建议白名单

- 生产网关 IP
- 现场 VPN 网段
- 运维堡垒机网段

## 明确禁止

- 对全网开放 `0.0.0.0/0`
- 将 `1883` 直接暴露到公网且无 ACL/认证
- 将开发测试设备与生产 Broker 共用同一入口

## 配套措施

- MQTT 用户名密码或证书认证
- Broker ACL，限制 topic 读写范围
- 连接失败、异常流量、重复重连接入告警
- 防火墙规则变更纳入上线单
