## 🎯 部署前准备

### 1. 硬件要求

| 资源类型 | 最低配置 | 推荐配置 | 说明 |
|---------|---------|---------|------|
| **CPU** | 4核 | 8核+ | 支持并发处理 |
| **内存** | 8GB | 16GB+ | TimescaleDB需要较多内存 |
| **磁盘** | 100GB SSD | 500GB+ SSD | 时序数据增长快 |
| **网络** | 100Mbps | 1Gbps | 支持大量设备连接 |

### 2. 软件要求

```bash
# 操作系统（任选其一）
- Ubuntu 20.04 LTS / 22.04 LTS（推荐）
- CentOS 7+ / Rocky Linux 8+
- Debian 11+

# 必需软件
- Docker 24.0+ 
- Docker Compose 2.0+
- Nginx 1.18+（用于反向代理）
- OpenSSL（用于SSL证书）
```

### 3. 网络规划

| 服务 | 内部端口 | 外部端口 | 说明 |
|-----|---------|---------|------|
| 后端API | 8088 | 80/443 | 通过Nginx暴露 |
| 数据库 | 5432 | - | 仅内网访问 |
| Redis | 6379 | - | 仅内网访问 |
| MQTT | 1883 | 1883 | 设备连接（可配置防火墙） |
| MQTT WS | 9001 | 9001 | WebSocket连接 |
| 前端 | 3000 | - | 通过Nginx暴露 |

### 4. 域名和证书准备

- **API域名**: `api.yourcompany.com` 或 `energy.yourcompany.com`
- **前端域名**: `energy.yourcompany.com` 或 `dashboard.yourcompany.com`
- **SSL证书**: Let's Encrypt（免费）或企业CA证书

## 🖥️ 服务器环境配置

### 1. 安装Docker和Docker Compose

```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER

# 安装Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 验证安装
docker --version
docker-compose --version
```

### 2. 创建部署目录结构

```bash
# 创建项目目录
sudo mkdir -p /opt/mine-energy-system
sudo chown $USER:$USER /opt/mine-energy-system
cd /opt/mine-energy-system

# 创建必要的目录
mkdir -p {logs,backups,ssl,nginx/conf.d,nginx/ssl}
```

### 3. 配置防火墙

```bash
# Ubuntu (UFW)
sudo ufw allow 22/tcp      # SSH
sudo ufw allow 80/tcp       # HTTP
sudo ufw allow 443/tcp      # HTTPS
sudo ufw allow 1883/tcp     # MQTT（如需要外网访问）
sudo ufw enable

# CentOS (firewalld)
sudo firewall-cmd --permanent --add-service=ssh
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --permanent --add-port=1883/tcp
sudo firewall-cmd --reload
```

## ⚙️ 生产环境配置

### 1. 创建生产环境docker-compose文件

创建 `docker-compose.prod.yml`:

```yaml
version: '3.8'

services:
  # 数据库 (TimescaleDB)
  db:
    image: timescale/timescaledb:latest-pg14
    container_name: mine_energy_db_prod
    restart: always
    environment:
      POSTGRES_USER: ${DB_USER:-admin}
      POSTGRES_PASSWORD: ${DB_PASSWORD}
      POSTGRES_DB: mine_energy
    volumes:
      - ./pg_data:/var/lib/postgresql/data
      - ./backups:/backups
    networks:
      - app_network
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ${DB_USER:-admin} -d mine_energy"]
      interval: 10s
      timeout: 5s
      retries: 3
      start_period: 30s
    # 生产环境不暴露端口到主机
    # ports:
    #   - "5432:5432"

  # Redis
  redis:
    image: redis:7.0-alpine
    container_name: ems_redis_prod
    restart: always
    command: redis-server --requirepass ${REDIS_PASSWORD}
    volumes:
      - redis_data_prod:/data
    networks:
      - app_network
    healthcheck:
      test: ["CMD", "redis-cli", "--no-auth-warning", "-a", "${REDIS_PASSWORD}", "ping"]
      interval: 10s
      timeout: 5s
      retries: 3

  # MQTT
  mqtt:
    image: eclipse-mosquitto:2.0
    container_name: mine_mqtt_prod
    restart: always
    ports:
      - "1883:1883"
      - "9001:9001"
    volumes:
      - ./mosquitto/config:/mosquitto/config
      - ./mosquitto/data:/mosquitto/data
      - ./mosquitto/log:/mosquitto/log
    networks:
      - app_network
    healthcheck:
      test: ["CMD-SHELL", "mosquitto_sub -h localhost -t '$$SYS/#' -C 1 | head -1 || exit 1"]
      interval: 10s
      timeout: 5s
      retries: 3

  # 后端应用
  backend:
    build:
      context: .
      dockerfile: Dockerfile
    container_name: mine_backend_prod
    restart: always
    environment:
      - DATABASE_URL=postgresql://${DB_USER:-admin}:${DB_PASSWORD}@db:5432/mine_energy
      - REDIS_URL=redis://:${REDIS_PASSWORD}@redis:6379/0
      - MQTT_BROKER=mqtt
      - MQTT_PORT=1883
      - SECRET_KEY=${SECRET_KEY}
      - DEBUG=False
      - LOG_LEVEL=INFO
      - HOST=0.0.0.0
      - PORT=8088
      - CORS_ORIGINS=${CORS_ORIGINS}
    volumes:
      - ./logs:/app/logs
    depends_on:
      db:
        condition: service_healthy
      redis:
        condition: service_healthy
      mqtt:
        condition: service_healthy
    networks:
      - app_network
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8088/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 40s

volumes:
  redis_data_prod:
    driver: local

networks:
  app_network:
    driver: bridge
```

### 2. 创建生产环境变量文件

创建 `.env.prod`:

```bash
# ==================== 数据库配置 ====================
DB_USER=admin
DB_PASSWORD=your-strong-database-password-change-me

# ==================== Redis配置 ====================
REDIS_PASSWORD=your-strong-redis-password-change-me

# ==================== JWT密钥 ====================
# 使用命令生成: python3 -c "import secrets; print(secrets.token_urlsafe(32))"
SECRET_KEY=your-super-secret-jwt-key-min-32-chars-change-me

# ==================== CORS配置 ====================
# 生产环境域名（JSON数组格式）
CORS_ORIGINS=["https://energy.yourcompany.com","https://dashboard.yourcompany.com"]

# ==================== MQTT配置（可选） ====================
# MQTT_USERNAME=admin
# MQTT_PASSWORD=your-mqtt-password
```

**⚠️ 重要**: 
- 所有密码必须使用强密码（至少16位，包含大小写字母、数字、特殊字符）
- 不要将 `.env.prod` 提交到版本控制系统
- 使用 `chmod 600 .env.prod` 限制文件权限

### 3. 生成强密码和密钥

```bash
# 生成数据库密码
openssl rand -base64 32

# 生成Redis密码
openssl rand -base64 32

# 生成JWT密钥
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

```bash
# 首次部署后，立即修改管理员密码
docker exec -it mine_backend_prod python scripts/python/create_admin.py

# 或通过API修改
curl -X POST http://localhost:8088/auth/change-password \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"old_password": "123456", "new_password": "your-new-strong-password"}'
```

### 2. 配置MQTT认证

编辑 `mosquitto/config/mosquitto.conf`:

```conf
# 允许匿名连接（生产环境建议关闭）
allow_anonymous false

# 密码文件
password_file /mosquitto/config/passwd

# ACL文件（访问控制列表）
acl_file /mosquitto/config/acl
```

创建MQTT用户密码文件:

```bash
# 进入MQTT容器
docker exec -it mine_mqtt_prod sh

# 创建密码文件
mosquitto_passwd -c /mosquitto/config/passwd admin
# 输入密码

# 创建ACL文件
cat > /mosquitto/config/acl <<EOF
user admin
topic read mine/telemetry
topic write mine/control/+
EOF
```

### 3. 数据库安全配置

```bash
# 限制数据库连接（编辑docker-compose.prod.yml）
```


## 🌐 Nginx反向代理配置

### 1. 安装Nginx

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install -y nginx

# CentOS/Rocky Linux
sudo yum install -y nginx
```

### 2. 创建Nginx配置文件

创建 `/etc/nginx/sites-available/mine-energy`:

```nginx
# 后端API服务器配置
upstream backend_api {
    server 127.0.0.1:8088;
    keepalive 32;
}

# 前端服务器配置（如果前端也通过Nginx部署）
upstream frontend {
    server 127.0.0.1:3000;
    keepalive 32;
}

# HTTP服务器（重定向到HTTPS）
server {
    listen 80;
    server_name api.yourcompany.com energy.yourcompany.com;

    # 重定向到HTTPS
    return 301 https://$server_name$request_uri;
}

# HTTPS服务器 - API
server {
    listen 443 ssl http2;
    server_name api.yourcompany.com;

    # SSL证书配置
    ssl_certificate /opt/mine-energy-system/ssl/fullchain.pem;
    ssl_certificate_key /opt/mine-energy-system/ssl/privkey.pem;
    
    # SSL优化配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 10m;

    # 安全头
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # 日志
    access_log /var/log/nginx/mine-energy-api-access.log;
    error_log /var/log/nginx/mine-energy-api-error.log;

    # 客户端最大请求体大小
    client_max_body_size 10M;

    # API代理
    location / {
        proxy_pass http://backend_api;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # WebSocket支持
    location /ws {
        proxy_pass http://backend_api/ws;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        
        # WebSocket超时设置
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
    }

    # 健康检查（可选，不记录日志）
    location /health {
        proxy_pass http://backend_api/health;
        access_log off;
    }
}

# HTTPS服务器 - 前端（如果前端通过Nginx部署）
server {
    listen 443 ssl http2;
    server_name energy.yourcompany.com;

    ssl_certificate /opt/mine-energy-system/ssl/fullchain.pem;
    ssl_certificate_key /opt/mine-energy-system/ssl/privkey.pem;
    
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    root /opt/mine-energy-system/frontend/dist;
    index index.html;

    # 前端静态文件
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API代理
    location /api {
        proxy_pass http://backend_api;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

### 3. 启用Nginx配置

```bash
# 创建符号链接
sudo ln -s /etc/nginx/sites-available/mine-energy /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启Nginx
sudo systemctl restart nginx
sudo systemctl enable nginx
```

## 🔐 HTTPS/SSL配置

### 方式1: 使用Let's Encrypt（免费，推荐）

```bash
# 安装Certbot
sudo apt install -y certbot python3-certbot-nginx

# 获取证书（自动配置Nginx）
sudo certbot --nginx -d api.yourcompany.com -d energy.yourcompany.com

# 证书会自动续期（cron任务）
# 验证续期
sudo certbot renew --dry-run
```

### 方式2: 使用企业CA证书

```bash
# 1. 将证书文件放到ssl目录
sudo cp your-certificate.crt /opt/mine-energy-system/ssl/fullchain.pem
sudo cp your-private-key.key /opt/mine-energy-system/ssl/privkey.pem

# 2. 设置权限
sudo chmod 600 /opt/mine-energy-system/ssl/privkey.pem
sudo chmod 644 /opt/mine-energy-system/ssl/fullchain.pem

# 3. 重启Nginx
sudo systemctl restart nginx
```

## 💾 数据备份与恢复

### 1. 自动备份脚本

创建 `scripts/shell/backup.sh`:

```bash
#!/bin/bash
# 数据库自动备份脚本

BACKUP_DIR="/opt/mine-energy-system/backups"
DATE=$(date +%Y%m%d_%H%M%S)
RETENTION_DAYS=30

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份数据库
docker exec mine_energy_db_prod pg_dump -U admin mine_energy | gzip > $BACKUP_DIR/backup_$DATE.sql.gz

# 删除30天前的备份
find $BACKUP_DIR -name "backup_*.sql.gz" -mtime +$RETENTION_DAYS -delete

echo "备份完成: backup_$DATE.sql.gz"
```

设置定时任务:

```bash
# 编辑crontab
crontab -e

# 每天凌晨2点备份
0 2 * * * /opt/mine-energy-system/scripts/shell/backup.sh >> /var/log/mine-energy-backup.log 2>&1
```

### 2. 手动备份

```bash
# 备份数据库
docker exec mine_energy_db_prod pg_dump -U admin mine_energy | gzip > backup_$(date +%Y%m%d).sql.gz

# 备份Redis（可选）
docker exec ems_redis_prod redis-cli --no-auth-warning -a YOUR_REDIS_PASSWORD SAVE
docker cp ems_redis_prod:/data/dump.rdb ./backups/redis_$(date +%Y%m%d).rdb

# 备份配置文件
tar -czf config_backup_$(date +%Y%m%d).tar.gz .env.prod docker-compose.prod.yml nginx/conf.d/
```

### 3. 恢复数据

```bash
# 恢复数据库
gunzip -c backup_20260124.sql.gz | docker exec -i mine_energy_db_prod psql -U admin mine_energy

# 恢复Redis（可选）
docker cp ./backups/redis_20260124.rdb ems_redis_prod:/data/dump.rdb
docker restart ems_redis_prod
```

```bash
# 创建健康检查脚本
cat > /opt/mine-energy-system/scripts/shell/health_check.sh <<'EOF'
#!/bin/bash
API_URL="https://api.yourcompany.com/health"

response=$(curl -s -o /dev/null -w "%{http_code}" $API_URL)

if [ $response -eq 200 ]; then
    echo "✅ 系统健康"
    exit 0

    echo "❌ 系统异常: HTTP $response"

# 添加到crontab（每5分钟检查一次）
*/5 * * * * /opt/mine-energy-system/scripts/shell/health_check.sh
```

## 🔄 高可用部署

### 1. 数据库主从复制（可选）

对于高可用场景，可以配置PostgreSQL主从复制：

```yaml
# docker-compose.ha.yml（示例）
services:
  db_master:
    # ... 主库配置
    environment:
      POSTGRES_REPLICATION_USER: replicator
      POSTGRES_REPLICATION_PASSWORD: replicator_password
  
  db_slave:
    # ... 从库配置
    environment:
      PGUSER: replicator
      POSTGRES_MASTER_SERVICE: db_master
```

### 2. Redis哨兵模式（可选）

```yaml
# Redis Sentinel配置（高可用）
services:
  redis_master:
    # 主Redis
  redis_slave:
    # 从Redis
  redis_sentinel:
    # Sentinel监控
```

### 3. 负载均衡

使用Nginx进行负载均衡:

```nginx
upstream backend_api {
    least_conn;  # 最少连接算法
    server 127.0.0.1:8088;
    server 127.0.0.1:8089;  # 第二个后端实例
    keepalive 32;
}
```

## 🛠️ 运维管理脚本

### 1. 部署脚本

创建 `scripts/shell/deploy.sh`:

```bash
#!/bin/bash
# 生产环境部署脚本

set -e

echo "🚀 开始部署..."

# 1. 拉取最新代码
git pull origin main

# 2. 构建镜像
docker-compose -f docker-compose.prod.yml build

# 3. 停止旧服务
docker-compose -f docker-compose.prod.yml down

# 4. 启动新服务
docker-compose -f docker-compose.prod.yml up -d

# 5. 等待服务就绪
sleep 30

# 6. 健康检查
curl -f http://localhost:8088/health || exit 1

echo "✅ 部署完成！"
```

### 2. 重启脚本

创建 `scripts/shell/restart.sh`:

```bash
#!/bin/bash
# 重启所有服务

docker-compose -f docker-compose.prod.yml restart

echo "✅ 服务已重启"
```

### 3. 查看状态脚本

创建 `scripts/shell/status.sh`:

```bash
#!/bin/bash
```
