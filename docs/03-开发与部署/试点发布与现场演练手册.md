# 试点发布与现场演练手册

> 用于把 MineEnergySystem 从“可运行”推进到“可试点交付”。建议在第一次真实站点部署前完整走一遍本手册。

---

## 1. 目标

本手册覆盖四件事：

- 发布前总检查
- 备份 / 恢复 / 回滚演练
- 部署后冒烟验收
- 告警通知通道验收

---

## 2. 演练前准备

### 必备配置

- 复制 `env.prod.example` 为 `.env.prod`
- 替换数据库、Redis、Grafana、JWT 密钥
- 设置真实 `CORS_ORIGINS` 与 `TRUSTED_HOSTS`
- 确认 `FORCE_HTTPS=True`
- 准备证书文件到 `nginx/ssl/`

### 必备环境

- Docker / Docker Compose 可用
- 数据库卷和备份目录有可写权限
- 现场域名和防火墙策略已确认
- 至少一名值守人能接收 Webhook 或邮件通知

---

## 3. 标准演练顺序

### 3.1 发布前检查

```bash
bash ./scripts/shell/release_readiness.sh
./venv/bin/python scripts/python/check_production_readiness.py --env-file .env.prod
```

如需把 readiness、容量基线、冒烟串成一次演练，可直接使用：

```bash
bash ./scripts/shell/pilot_drill.sh
```

### 3.2 备份与恢复校验

```bash
bash ./scripts/shell/backup.sh --label pilot_drill
bash ./scripts/shell/restore.sh --verify-only backups/latest_pilot_drill.dump
bash ./scripts/shell/restore_drill.sh
```

### 3.3 部署

```bash
bash ./scripts/shell/deploy_prod.sh
```

### 3.4 部署后冒烟

```bash
bash ./scripts/shell/pilot_smoke_test.sh
SMOKE_USERNAME=admin SMOKE_PASSWORD='your-password' bash ./scripts/shell/pilot_smoke_test.sh
```

### 3.5 通知通道验证

```bash
./venv/bin/python scripts/python/send_test_alert.py
```

如需做容量基线，建议额外执行：

```bash
python scripts/python/stress_test.py --endpoint /health/live --workers 20 --duration-seconds 60 --output artifacts/load/health_live.json
python scripts/python/stress_test.py --endpoint /auth/login --method POST --body-json '{"username":"admin","password":"your-password"}' --workers 10 --duration-seconds 30 --output artifacts/load/auth_login.json
```

### 3.6 回滚预演

```bash
bash ./scripts/shell/rollback_prod.sh backups/latest_pre_deploy.dump
```

## 4. 现场值守清单

首站试运行期间建议每天检查：

- `/health` `/ready` `/live` `/metrics`
- Grafana 面板是否持续出数
- MQTT 失败、重复、死信是否增长
- 后端 5xx、超时、重启次数
- 告警是否存在误报或漏报
- 当日备份是否生成且可校验

---

## 5. 交付责任划分

建议至少明确以下责任人：

- 应用负责人：发布、回滚、接口可用性
- 数据库负责人：迁移、备份、恢复
- MQTT / 网关负责人：设备接入、断点补传、协议变更
- 网络与安全负责人：域名、证书、防火墙、反向代理
- 值守负责人：告警接收、现场响应、升级通知

---

## 6. 退出条件

满足以下条件后再进入正式投产审批：

- 连续运行 7-14 天无阻塞性故障
- 备份、恢复、回滚至少各演练一次
- 告警通知已接正式渠道并完成验收
- 真实设备接入规范已冻结
- 值守人与故障升级路径已确认
