## 🚀 快速部署（5步）

### 第1步：准备服务器

```bash
# 1. 安装Docker和Docker Compose
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER

# 2. 创建项目目录
sudo mkdir -p /opt/mine-energy-system
sudo chown $USER:$USER /opt/mine-energy-system
cd /opt/mine-energy-system
```

### 第2步：获取代码

```bash
# 方式1: Git克隆
git clone https://github.com/your-repo/MineEnergySystem.git .

# 方式2: 上传代码包
# 将项目代码上传到服务器
```

### 第3步：配置环境变量

```bash
# 1. 复制配置模板
cp env.prod.example .env.prod

# 2. 编辑配置文件
vim .env.prod  # 或使用其他编辑器

# 3. 必须修改的配置：
#    - DB_PASSWORD: 数据库密码
#    - REDIS_PASSWORD: Redis密码
#    - SECRET_KEY: JWT密钥（使用命令生成）
#    - CORS_ORIGINS: 前端域名

# 生成JWT密钥
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

### 第4步：部署服务

```bash
# 使用部署脚本（推荐）
./scripts/shell/deploy_prod.sh

# 或手动部署
docker-compose -f docker-compose.prod.yml --env-file .env.prod up -d
```

### 第5步：配置Nginx（可选）

```bash
# 1. 安装Nginx
sudo apt install -y nginx

# 2. 配置反向代理（参考完整指南）

# 3. 配置SSL证书
sudo certbot --nginx -d api.yourcompany.com
```

## 🔧 常用命令

### 服务管理

```bash
# 启动服务
docker-compose -f docker-compose.prod.yml --env-file .env.prod up -d

# 停止服务
docker-compose -f docker-compose.prod.yml down

# 重启服务
docker-compose -f docker-compose.prod.yml restart

# 查看日志
docker-compose -f docker-compose.prod.yml logs -f

# 查看状态
docker-compose -f docker-compose.prod.yml ps
```

### 数据备份

```bash
# 手动备份
./scripts/shell/backup.sh

# 恢复数据
./scripts/shell/restore.sh backup_20260124_020000.sql.gz

# 设置自动备份（每天凌晨2点）
crontab -e
# 添加: 0 2 * * * /opt/mine-energy-system/scripts/shell/backup.sh
```

### 健康检查

```bash
# API健康检查
curl http://localhost:8088/health

# 数据库连接
docker exec mine_energy_db_prod psql -U admin -d mine_energy -c "SELECT 1;"

# Redis连接
docker exec ems_redis_prod redis-cli -a YOUR_REDIS_PASSWORD ping
```

## 🔐 安全加固

### 1. 修改默认密码

```bash
# 通过API修改
curl -X POST http://localhost:8088/auth/change-password \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"old_password": "123456", "new_password": "your-new-password"}'
```

### 2. 配置防火墙

```bash
# Ubuntu
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
```

## 🆘 故障排查

### 服务无法启动

```bash
# 查看日志
docker-compose -f docker-compose.prod.yml logs

# 检查端口占用
netstat -tlnp | grep -E "8088|5432|6379"
```

### 数据库连接失败

```bash
# 测试连接
docker exec -it mine_energy_db_prod psql -U admin -d mine_energy

# 查看数据库日志
docker logs mine_energy_db_prod
```

### 健康检查失败

```bash
# 检查服务状态
docker-compose -f docker-compose.prod.yml ps

# 手动健康检查
curl -v http://localhost:8088/health
```
