以下事项不影响进入单站试点，但仍建议在正式投产前补齐：

- GitHub Actions 远端部署工作流尚未在真实 GitHub Environment 中完成实跑

- 现场真实设备批量接入与长时间稳定性观察仍需安排
- `metrics` 端点可用，但当前未暴露 `process_*` 指标；如运维侧需要标准进程指标，建议后续增强
