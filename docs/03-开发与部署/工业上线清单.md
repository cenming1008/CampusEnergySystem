## 2. 上线前必须确认

### 配置与密钥

- [ ] `.env.prod` 已创建，且未使用示例默认密码
- [ ] 已执行 `python scripts/python/generate_prod_secrets.py` 或等效方式生成强密码
- [ ] `SECRET_KEY` 已替换为强随机值
- [ ] `DB_PASSWORD` / `REDIS_PASSWORD` / `GRAFANA_ADMIN_PASSWORD` 已替换
- [ ] `TRUSTED_HOSTS` 已改成真实域名
- [ ] `FORCE_HTTPS=True`
- [ ] `WORKERS >= 2`
- [ ] `ALERTING_WEBHOOK_URL` 或邮件配置已接正式通知渠道

### 数据库与迁移

- [ ] 已执行 `alembic upgrade head`
- [ ] 旧库升级前已备份
- [ ] 恢复演练至少成功一次
- [ ] 关键表索引已确认存在

### 部署与反向代理

- [ ] Nginx 配置已生效
- [ ] HTTPS 证书已就位
- [ ] 80/443 端口与防火墙策略已确认
- [ ] 数据库和 Redis 未直接暴露到公网

### 监控与值守

- [ ] Prometheus 已可抓到 `/metrics`
- [ ] Grafana 面板可正常展示
- [ ] Alertmanager 路由已改成正式接收方
- [ ] 至少验证一次“模拟告警 -> 通知送达”

### 备份与回滚

- [ ] `backup.sh` 已跑通
- [ ] `restore.sh --verify-only` 已跑通
- [ ] `restore_drill.sh` 已生成一次演练记录
- [ ] `rollback_prod.sh` 已演练
- [ ] `pre_deploy` 备份流程已确认

## 3. 推荐上线前命令

```bash
# 1. 发布前总检查
bash ./scripts/shell/release_readiness.sh

# 2. 迁移数据库
alembic upgrade head

# 3. 生产配置检查
./venv/bin/python scripts/python/check_production_readiness.py --env-file .env.prod

# 4. 手动做一次部署前备份
bash ./scripts/shell/backup.sh --label manual

# 5. 验证备份
bash ./scripts/shell/restore.sh --verify-only backups/latest_manual.sql.gz

# 5.1 完整恢复演练
bash ./scripts/shell/restore_drill.sh

# 6. 部署
bash ./scripts/shell/deploy_prod.sh
```

## 4. 建议上线后观察的指标

### 前 30 分钟重点看

- HTTP 5xx 错误率
- HTTP p95 延迟
- MQTT `failed / dead_letter / duplicate`
- 调度任务失败次数
- 数据库连接与慢查询
- Redis / MQTT / Scheduler 健康状态

### 前 24 小时重点看

- 告警通知是否过多或漏发
- 数据写入量是否符合预期
- 死信是否持续增长
- 备份是否按计划产出
