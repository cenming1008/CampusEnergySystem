## 🎯 核心概念

### 1. 统一架构

```
旧系统（分散）:
  DeviceData (电力)
  EnergyData (多能源)
  ↓
新系统（统一）:
  EnergyData (所有能源)
```

### 2. 智能配置

```
创建设备只需 3 个字段:
  - name: 设备名称
  - sn: 序列号
  - device_type: 设备类型

系统自动配置其他所有字段！
```

### 3. 统一接口

```
所有设备使用同一个数据上报接口:
  POST /devices/{id}/data
```

### 4. 11 种设备类型

```
电力系统 (5种):
  ⚡ load - 用电设备
  ☀️ solar - 光伏发电
  💨 wind - 风力发电
  🔋 storage - 储能设备
  🔌 charger - 充电桩

其他能源 (6种):
  💧 water_meter - 水表
  🔥 gas_meter - 燃气表
  🌡️ heat_meter - 热量表
  💨 steam_meter - 蒸汽表
  ❄️ cooling_meter - 冷量表
```

## 💻 代码示例

### 创建设备

```python
from app.services.device_service import DeviceService

# 只需 3 个字段！
device = DeviceService.create_device_smart(
    session,
    name="1号水表",
    sn="WATER001",
    device_type="water_meter"
)
# 自动配置: energy_type, category, unit, capacity...
```

### 上报数据

```python
# 统一接口，适用所有设备
DeviceService.report_device_data(
    session,
    device_id=1,
    data={
        "consumption": 10.5,
        "flow_rate": 2.3,
        "pressure": 0.3
    }
)
# 自动: 验证字段、保存数据、计算碳排放
```

### 查询数据

```python
# 简单查询
data = DeviceService.get_device_data(
    session,
    device_id=1,
    start_time=start,
    end_time=end
)
```

## 🐛 常见问题

### Q1: 初始化失败怎么办？

```bash
# 检查服务状态
docker-compose ps

# 查看日志
docker-compose logs backend

# 重启服务
docker-compose restart
```

### Q2: 如何添加新设备类型？

编辑 `app/core/device_registry.py`，添加配置，重启服务。

### Q3: 数据存在哪里？

统一存储在 `EnergyData` 表，TimescaleDB 自动优化。

### Q4: 如何查看碳排放？

```bash
GET /energy/carbon/summary?start_time=...&end_time=...
```

### Q5: 生产环境注意什么？

- 修改默认密码
- 配置 HTTPS
- 设置防火墙
- 定期备份数据库
