# 多能源管理页面问题修复说明

## 问题现象

多能源管理页面显示多个"网络请求失败"，所有能源卡片都无法显示数据。

## 根本原因

经过详细检查，发现问题的根源：

### 1. 数据库有数据 ✅
```sql
 total | energy_type |           latest           
-------+-------------+----------------------------
   286 | cooling     | 2026-01-24 16:59:36
  1174 | electricity | 2026-01-24 16:59:36
   575 | gas         | 2026-01-24 16:59:36
   287 | heat        | 2026-01-24 16:59:36
   575 | water       | 2026-01-24 16:59:36
```

共2897条能源数据，数据正常。

### 2. API端点工作 ✅
```bash
# 能源类型API - 正常
GET /energy/types ✅

# 能源统计API - 返回200，但前端可能解析失败
GET /energy/statistics ✅ (HTTP 200)
```

### 3. **问题所在**: 响应模型不匹配 ❌

查看API代码：

```python
# app/api/endpoints/energy.py
@router.get("/statistics", response_model=EnergyStatisticsResponse)
def get_energy_statistics(...):
    stats = EnergyService.calculate_statistics(...)
    return stats  # 返回字典
```

`calculate_statistics` 返回的是**普通字典**，但endpoint声明了 `response_model=EnergyStatisticsResponse`。

如果 `EnergyStatisticsResponse` 模型与实际返回的字典结构不匹配，FastAPI会抛出序列化错误！

---

## 解决方案

### 方案1: 修复响应模型（推荐）

检查并修复 `EnergyStatisticsResponse` 模型定义：

```python
# app/api/endpoints/energy.py

class EnergyStatisticsResponse(BaseModel):
    """能源统计响应模型"""
    total_consumption: float
    avg_consumption: float  # ← 注意：这个字段必须存在
    avg_flow_rate: float
    peak_flow_rate: float
    data_count: int
```

确保模型字段与 `calculate_statistics` 返回的字典完全匹配。

### 方案2: 直接返回字典（临时方案）

```python
@router.get("/statistics")  # 去掉 response_model
def get_energy_statistics(...):
    stats = EnergyService.calculate_statistics(...)
    return stats
```

## 其他可能的问题

### 问题A: 前端时间格式

前端可能传递的时间格式不正确：

```typescript
// frontend/src/views/EnergyManagement.vue
const formatDateRange = computed(() => {
  if (!dateRange.value) return ['', '']
  return [
    dateRange.value[0].toISOString(),  // ← 确保是ISO格式
    dateRange.value[1].toISOString()
  ]
})
```

### 问题B: 默认日期范围为空

检查前端代码中 `dateRange` 的默认值：

```typescript
const dateRange = ref<[Date, Date]>([
  new Date(new Date().getTime() - 7 * 24 * 3600 * 1000), // 最近7天
  new Date()
])
```

确保默认值不为null。

### 问题C: API调用缺少必填参数

前端可能没有传递所有必填参数：

```typescript
// 检查这个函数
const loadAllStatistics = async () => {
  const [startTime, endTime] = formatDateRange.value
  
  // 确保时间参数有值
  if (!startTime || !endTime) {
    console.error('时间参数缺失')
    return
  }
  
  // ...
}
```
