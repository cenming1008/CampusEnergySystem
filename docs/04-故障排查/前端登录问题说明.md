# 前端"网络请求失败"问题说明

## 问题原因

从你的截图看到"多能源管理中心"页面显示多个"网络请求失败"。

**根本原因：你还没有登录系统！**

所有能源管理相关的API都需要**JWT认证**，未登录时会返回：
```json
{"detail":"Not authenticated"}
```

## ✅ 解决方案

### 1. 先登录系统

1. 访问：http://localhost:3000
2. 会自动跳转到登录页（如果没有token）
3. 输入默认账号：
   - **用户名**：`admin`
   - **密码**：`123456`
4. 点击"立即登录"

### 2. 登录成功后

- 会自动跳转到Dashboard（驾驶舱首页）
- 浏览器会保存token到localStorage
- 所有后续API请求会自动带上认证头：`Authorization: Bearer <token>`

### 3. 然后访问多能源管理

- 点击左侧菜单的"多能源管理"
- 此时应该能正常加载数据了
- 不会再显示"网络请求失败"

---

## 🔍 为什么直接访问失败？

从代码分析：

1. **路由守卫**（`frontend/src/router/index.ts`）：
```typescript
router.beforeEach((to, from, next) => {
  const authStore = useAuthStore()
  
  if (to.name === 'Login') {
    next()
    return
  }

  if (!authStore.token) {
    // 没登录，强制去登录页
    next({ name: 'Login' })
  } else {
    next()
  }
})
```

2. **请求拦截器**（`frontend/src/utils/request.ts`）：
```typescript
service.interceptors.request.use(
  (config: InternalAxiosRequestConfig) => {
    const authStore = useAuthStore()
    if (authStore.token) {
      config.headers.Authorization = `Bearer ${authStore.token}`
    }
    return config
  }
)
```

**问题**：如果直接访问 `/energy` 路径，可能绕过了路由守卫，但没有token，导致API请求全部失败。

## 🐛 如果登录后仍然失败

### 检查1: Token是否过期

JWT token默认5小时有效期（300分钟）。如果过期：
```javascript
// Console中会看到
401 Unauthorized
// 页面会显示"登录已过期，请重新登录"
```

**解决**：重新登录即可

### 检查2: 请求头是否正确

在Network选项卡中点击失败的请求，查看Request Headers：

**正确的请求头应该包含**：
```
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**如果没有这个头**：
- 说明前端没有正确添加token
- 检查 `useAuthStore` 中的token是否存在

### 检查3: CORS是否正常

Response Headers中应该有：
```
access-control-allow-origin: http://localhost:3000
access-control-allow-credentials: true
```

如果没有：
- 检查后端 `.env` 文件的 `CORS_ORIGINS` 配置
- 重启后端服务

## 🎯 完整测试流程

### 1. 清除所有数据重新开始

```bash
# 浏览器Console
localStorage.clear()
sessionStorage.clear()

# 然后刷新页面
location.reload()
```

### 2. 手动测试登录API

```javascript
// 在浏览器Console中执行
fetch('http://localhost:8088/auth/login', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/x-www-form-urlencoded',
  },
  body: 'username=admin&password=123456'
})
  .then(r => r.json())
  .then(data => {
    console.log('登录成功:', data)
    localStorage.setItem('access_token', data.access_token)
    localStorage.setItem('username', 'admin')
  })
```

### 3. 测试带token的API请求

```javascript
// 获取能源类型
fetch('http://localhost:8088/energy/types', {
  headers: {
    'Authorization': `Bearer ${localStorage.getItem('access_token')}`
  }
})
  .then(r => r.json())
  .then(data => console.log('能源类型:', data))
```

如果这个能成功返回数据，说明：
- ✅ 后端API正常
- ✅ 认证机制正常
- ✅ CORS配置正确

那么问题就在前端的自动登录流程或token管理。

## 💡 调试提示

### 打开详细日志

在 `frontend/src/utils/request.ts` 中添加日志：

```typescript
service.interceptors.request.use(
  (config: InternalAxiosRequestConfig) => {
    const authStore = useAuthStore()
    
    // 添加这行日志
    console.log('🔑 发送请求:', config.url, 'Token:', authStore.token ? '已设置' : '未设置')
    
    if (authStore.token) {
      config.headers.Authorization = `Bearer ${authStore.token}`
    }
    return config
  }
)
```

这样你就能在Console中看到每个请求是否带了token。
