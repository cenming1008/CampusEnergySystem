## 🔧 如果仍有问题

### 问题1: 浏览器缓存导致

**症状**: 页面显示旧的错误，即使已修复

**解决**:
```
1. 按 Cmd/Ctrl + Shift + R (硬刷新)
2. 或清除浏览器缓存
3. 或使用无痕模式测试
```

### 问题2: API请求返回404

**症状**: `/energy/*` 等API返回404

**原因**: Vite没有正确重载配置

**解决**:
```bash
# 停止前端 (Ctrl+C)
cd frontend
npm run dev
```

### 问题3: WebSocket连接失败

**症状**: 
- Console显示 "WebSocket 连接错误"
- Network显示 `/ws` 请求失败

**检查**:
1. 后端是否运行在8088端口
2. Vite配置中 `/ws` 代理是否正确

**临时解决**:

在 `frontend/src/stores/useSocketStore.ts` 中，WebSocket已配置了自动回退机制：
- 优先通过Vite代理连接
- 失败后自动尝试直接连接 `ws://localhost:8088/ws`

### 问题4: 401认证错误

**症状**: 所有API请求都返回401

**这是正常的！** 因为：
1. 登录前访问需要认证的API会返回401
2. 登录后会自动在请求头中加入 `Authorization: Bearer <token>`

**如何验证token是否有效**:

在浏览器Console中执行：
```javascript
// 查看存储的token
localStorage.getItem('access_token')
localStorage.getItem('username')
```
