## 🎯 快速参考

### 创建设备

```bash
POST /devices/
{
  "name": "设备名称",
  "sn": "序列号", 
  "device_type": "设备类型"
}
```

### 上报数据

```bash
POST /devices/{id}/data
{
  "consumption": 消耗量,
  "flow_rate": 瞬时值
}
```

### 查询设备

```bash
GET /devices/
GET /devices/{id}
GET /devices/types
```

### 查询数据

```bash
GET /devices/{id}/data
GET /devices/{id}/statistics
```
