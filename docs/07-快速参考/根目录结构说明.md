# 项目根目录结构说明

> 矿区能源管理系统根目录文件和目录说明（原 ROOT_DIRECTORY.md，已迁入 docs）

## 📁 目录结构

```
MineEnergySystem/
├── README.md                    # 项目主文档 ⭐
├── CHANGELOG_v2.2.0.md          # 当前版本更新日志
├── app/                         # 后端应用（FastAPI）
├── frontend/                    # 前端应用（Vue 3）
├── lstm_forecast/               # LSTM 预测模块
├── config/                      # 配置文件
├── models/                      # LSTM 模型存储
├── scripts/                     # 脚本工具集（Python + Shell）
├── bin/                         # 快速启动脚本（fast_start.sh 等）
├── docs/                        # 完整文档（本目录所在）
├── docker-compose*.yml          # Docker 配置
├── Dockerfile、requirements.txt、run.py
├── env.example / env.local.example / env.prod.example
├── pg_data/、pg_data_dev/       # 数据库数据（已忽略）
└── mosquitto/                   # MQTT 配置
```
