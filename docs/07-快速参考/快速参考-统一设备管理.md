# 统一设备管理 - 快速参考卡片

> v2.2.0 新功能速查表

---

## 🚀 5 分钟快速上手

### 1. 查看支持的设备类型

```bash
GET /devices/types
```

**返回**: 11 种设备类型（电力、水、气、热、冷等）

---

### 2. 智能创建设备

```bash
POST /devices/
{
  "name": "1号水表",
  "sn": "WATER001",
  "device_type": "water_meter"
}
```

✨ **系统自动设置**: energy_type, category, unit, capacity

---

### 3. 上报数据

```bash
POST /devices/{device_id}/data
{
  "consumption": 10.5,
  "flow_rate": 2.3,
  "pressure": 0.3
}
```

✨ **系统自动**: 验证字段、保存数据、计算碳排放

---

### 4. 查询数据

```bash
GET /devices/{device_id}/data?start_time=...&end_time=...
```

---

### 5. 统计分析

```bash
GET /devices/{device_id}/statistics?start_time=...&end_time=...
```

## 🔍 常用操作

### 筛选设备

```bash
# 按能源类型
GET /devices/?energy_type=water

# 按设备类别
GET /devices/?category=water_meter

# 按状态
GET /devices/?is_active=true

# 组合筛选
GET /devices/?energy_type=electricity&category=solar&is_active=true
```

### 查看设备详情

```bash
GET /devices/{device_id}
```

### 更新设备

```bash
PUT /devices/{device_id}
{
  "name": "新名称",
  "location": "新位置"
}
```

### 切换设备状态

```bash
POST /devices/{device_id}/toggle?active=true
```

## 🛠️ Python 示例

### 创建设备

```python
from app.services.device_service import DeviceService

device = DeviceService.create_device_smart(
    session,
    name="1号水表",
    sn="WATER001",
    device_type="water_meter",
    location="A栋1层"
)
```

### 上报数据

```python
data = {
    "consumption": 10.5,
    "flow_rate": 2.3,
    "pressure": 0.3
}

energy_data = DeviceService.report_device_data(
    session,
    device_id=device.id,
    data=data
)
```

```python
data_list = DeviceService.get_device_data(
    session,
```

## 🎯 最佳实践

### ✅ 推荐

- 使用智能创建接口 `POST /devices/`
- 使用统一数据上报 `POST /devices/{id}/data`
- 设备序列号使用规范格式: `{TYPE}{NUMBER}`
- 及时更新设备位置信息

### ❌ 不推荐

- 手动填写所有设备字段
- 使用多个端点上报数据
- 随意命名设备序列号
- 忽略设备分类

## 🔧 添加新设备类型

只需编辑配置文件：

```python
# app/core/device_registry.py

self.register(DeviceTypeConfig(
    device_type="new_type",
    category=DeviceCategory.LOAD,
    energy_type=EnergyType.ELECTRICITY,
    name_zh="新设备",
    name_en="New Device",
    unit="kW",
    default_capacity=100.0,
    required_fields=["consumption"],
    optional_fields=["voltage", "current"]
))
```

重启服务即可使用！

## 🆚 新旧对比

### 创建设备

```bash
# 旧方式 - 需要手动填写 7+ 字段
POST /devices/
{
  "name": "1号水表",
  "sn": "WATER001",
  "device_type": "water_meter",
  "device_category": "water_meter",  # 手动
  "energy_type": "water",            # 手动
  "unit": "m³/h",                    # 手动
  "rated_capacity": 50.0             # 手动
}

# 新方式 - 只需 3 个字段 ✨
POST /devices/
{
  "name": "1号水表",
  "sn": "WATER001",
  "device_type": "water_meter"  # 自动配置其他字段
}
```

### 数据上报

```bash
# 旧方式 - 多个端点
POST /telemetry/upload        # 电力
POST /energy/data            # 多能源

# 新方式 - 统一接口 ✨
POST /devices/{id}/data      # 所有设备
```
