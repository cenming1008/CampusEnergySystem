# 本地开发快速参考

> 将 Docker 服务（TimescaleDB、MQTT、Redis）与本地 Backend/Frontend 结合的开发模式

---

## 🚀 一键启动

```bash
# 1. 启动 Docker 服务（只需运行一次）
bash scripts/shell/start_dev_env.sh

# 2. 配置环境变量（首次需要）
cp env.local.example .env

# 3. 启动 Backend（新终端）
source venv/bin/activate  # 激活虚拟环境
python run.py

# 4. 启动 Frontend（新终端）
cd frontend
npm run dev
```

---

## 📊 服务地址

| 服务 | 地址 | 说明 |
|------|------|------|
| **Frontend** | http://localhost:5173 | Vue3 前端界面 |
| **Backend API** | http://localhost:8088 | FastAPI 后端接口 |
| **API 文档** | http://localhost:8088/docs | Swagger 交互式文档 |
| **TimescaleDB** | localhost:5432 | 数据库（Docker） |
| **MQTT** | localhost:1883 | 消息队列（Docker） |
| **Redis** | localhost:6379 | 缓存（Docker） |

## 🛠️ 常用命令

### Docker 服务管理

```bash
# 启动 Docker 服务
bash scripts/shell/start_dev_env.sh

# 停止 Docker 服务
bash scripts/shell/stop_dev_env.sh

# 查看 Docker 服务状态
docker-compose -f docker-compose.dev.yml ps

# 查看 Docker 服务日志
docker-compose -f docker-compose.dev.yml logs -f

# 重启某个服务
docker-compose -f docker-compose.dev.yml restart db    # 数据库
docker-compose -f docker-compose.dev.yml restart mqtt  # MQTT
docker-compose -f docker-compose.dev.yml restart redis # Redis
```

### Backend 管理

```bash
# 启动 Backend（热重载模式）
python run.py

# 或使用 uvicorn 直接启动
uvicorn app.main:app --host 0.0.0.0 --port 8088 --reload

# 查看日志
tail -f logs/app.log

# 重建数据库
python scripts/python/rebuild_database.py

# 创建管理员
python scripts/python/create_admin.py

# 启动模拟器
python scripts/python/simulator.py
```

### Frontend 管理

```bash
# 安装依赖
cd frontend && npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

## 🔍 健康检查

```bash
# 检查所有 Docker 服务
docker-compose -f docker-compose.dev.yml ps

# 测试数据库连接
docker exec mine_energy_db_dev pg_isready -U admin

# 测试 Redis 连接
docker exec ems_redis_dev redis-cli ping

# 测试 Backend API
curl http://localhost:8088/health

# 测试 Frontend
curl http://localhost:5173
```

## 🐛 调试技巧

### Backend 调试

1. **使用 VSCode/PyCharm 调试器**
   - 设置断点
   - 单步执行
   - 查看变量

2. **查看实时日志**
   ```bash
   tail -f logs/app.log
   ```

3. **热重载**
   - 修改代码自动重启
   - 无需手动重启服务

### Frontend 调试

1. **浏览器开发者工具**
   - F12 打开 DevTools
   - Network 标签查看 API 请求
   - Console 查看日志

2. **Vue DevTools**
   - 安装 Vue DevTools 浏览器插件
   - 查看组件状态和事件

### Docker 调试

```bash
# 进入数据库容器
docker exec -it mine_energy_db_dev bash
docker exec -it mine_energy_db_dev psql -U admin -d mine_energy

# 进入 Redis 容器
docker exec -it ems_redis_dev redis-cli

# 查看容器日志
docker logs mine_energy_db_dev
docker logs mine_mqtt_dev
docker logs ems_redis_dev
```

## ❓ 常见问题

### 端口被占用

```bash
# 查看端口占用
lsof -i :5432  # TimescaleDB
lsof -i :1883  # MQTT
lsof -i :6379  # Redis
lsof -i :8088  # Backend
lsof -i :5173  # Frontend

# 杀掉占用端口的进程
kill -9 <PID>
```

### Docker 服务启动失败

```bash
# 查看详细日志
docker-compose -f docker-compose.dev.yml logs

# 重新启动
docker-compose -f docker-compose.dev.yml down
docker-compose -f docker-compose.dev.yml up -d
```

### Backend 连接失败

1. 检查 `.env` 文件配置
2. 确保使用 `localhost` 而不是 Docker 服务名
3. 确认 Docker 服务正在运行
