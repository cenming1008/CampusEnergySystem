## 📚 核心概念

### 什么是设备分组？

**设备分组 = 给设备打标签/分类**

```
示例：
- 1309电表 → [关键设备, 办公设备]
- 锅炉A   → [关键设备, 生产设备]
- 1310电表 → [办公设备]
```

### 为什么需要分组？

✅ **灵活分类**：一个设备可以属于多个分组
✅ **便于管理**：按分组查看和管理设备
✅ **权限控制**：不同分组不同权限
✅ **监控分级**：关键设备重点监控

## 🔧 基本操作

### 创建分组

```bash
curl -X POST http://localhost:8088/device-groups/ \
  -H "Content-Type: application/json" \
  -d '{
    "name": "关键设备",
    "code": "GROUP-CRITICAL",
    "group_type": "critical",
    "description": "需要重点监控的设备"
  }'
```

**返回：**
```json
{
  "id": 1,
  "name": "关键设备",
  "code": "GROUP-CRITICAL",
  "group_type": "critical"
}
```

### 添加设备到分组

```bash
curl -X POST http://localhost:8088/device-groups/1/devices \
  -H "Content-Type: application/json" \
  -d '{
    "device_id": 1,
    "note": "主生产线关键设备"
  }'
```

**重要：** 同一个设备可以多次添加到不同分组！

```bash
# 设备1加入分组1
POST /device-groups/1/devices {"device_id": 1}

# 设备1还可以加入分组2
POST /device-groups/2/devices {"device_id": 1}

# ✅ 这就是多对多关系！
```

### 查询分组的设备

```bash
# 查询分组1的所有设备
curl http://localhost:8088/device-groups/1/devices
```

### 查询设备的分组

```python
from app.services.device_group_service import DeviceGroupService

# 查询设备1属于哪些分组
groups = DeviceGroupService.get_device_groups(session, device_id=1)

for group in groups:
    print(f"- {group.name}")
```

## 🎨 实际应用

### 场景1：监控中心查看关键设备

```bash
# 1. 创建"关键设备"分组
POST /device-groups/ 
{
  "name": "关键设备",
  "group_type": "critical"
}

# 2. 添加重要设备
POST /device-groups/1/devices {"device_id": 1}
POST /device-groups/1/devices {"device_id": 5}
POST /device-groups/1/devices {"device_id": 10}

# 3. 监控中心查询
GET /device-groups/1/devices
# 返回所有关键设备
```

### 场景2：按负责人分组

```bash
# 张三负责的设备
POST /device-groups/ 
{
  "name": "张三负责",
  "manager": "张三"
}

# 李四负责的设备
POST /device-groups/ 
{
  "name": "李四负责",
  "manager": "李四"
}

# 共同负责的设备可以同时加入两个组
POST /device-groups/1/devices {"device_id": 1}
POST /device-groups/2/devices {"device_id": 1}
```

### 场景3：维护计划分组

```bash
# 每日巡检设备
POST /device-groups/ 
{
  "name": "每日巡检",
  "group_type": "maintenance"
}

# 每周维护设备
POST /device-groups/ 
{
  "name": "每周维护",
  "group_type": "maintenance"
}

# 同一设备可能既需要每日巡检，又需要每周维护
```

## 🔑 核心API

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/device-groups/` | 获取分组列表 |
| POST | `/device-groups/` | 创建分组 |
| GET | `/device-groups/{id}` | 获取分组详情 |
| PUT | `/device-groups/{id}` | 更新分组 |
| DELETE | `/device-groups/{id}` | 删除分组 |
| GET | `/device-groups/{id}/devices` | 获取分组设备 |
| POST | `/device-groups/{id}/devices` | 添加设备 |
| DELETE | `/device-groups/{id}/devices/{device_id}` | 移除设备 |
| GET | `/device-groups/{id}/statistics` | 分组统计 |

## 💡 常见问题

### Q1: 一个设备可以属于多个分组吗？

**A:** ✅ 可以！这就是多对多关系的优势。

```bash
# 设备1可以同时属于多个分组
POST /device-groups/1/devices {"device_id": 1}  # 关键设备
POST /device-groups/2/devices {"device_id": 1}  # 生产设备
POST /device-groups/3/devices {"device_id": 1}  # 办公设备
```

### Q2: 如何查看设备属于哪些分组？

**A:** 使用服务层方法：

```python
from app.services.device_group_service import DeviceGroupService

groups = DeviceGroupService.get_device_groups(session, device_id=1)
```

### Q3: 删除分组会删除设备吗？

**A:** ❌ 不会！只会删除分组关系，设备本身不受影响。

### Q4: 分组类型有哪些？

**A:** 预定义了4种（可以自定义）：
- `production` - 生产设备
- `office` - 办公设备
- `critical` - 关键设备
- `backup` - 备用设备

### Q5: 与位置管理有什么区别？

| 特性 | 位置管理 | 设备分组 |
|------|---------|---------|
| 关系 | 一对多 | 多对多 |
| 用途 | 物理位置 | 逻辑分类 |
| 示例 | A栋3单元1309 | 关键设备、生产设备 |
| 数量 | 一个设备一个位置 | 一个设备多个分组 |
