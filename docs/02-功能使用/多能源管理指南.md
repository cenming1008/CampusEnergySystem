## 功能概述

### 支持的能源类型

| 能源类型 | 编码 | 单位 | 碳排放因子 |
|---------|------|------|-----------|
| 电力 | `electricity` | kWh | 0.5839 kg CO2/kWh |
| 水 | `water` | m³ | 0.167 kg CO2/m³ |
| 燃气 | `gas` | m³ | 2.162 kg CO2/m³ |
| 热力 | `heat` | GJ | 0.11 kg CO2/kWh |
| 冷气 | `cooling` | kWh | 0.13 kg CO2/kWh |
| 蒸汽 | `steam` | t | 0.12 kg CO2/kg |

### 核心功能

- ✅ **多能源数据采集** - 统一的数据模型支持所有能源类型
- ✅ **自动碳排放计算** - 实时计算并记录碳排放量
- ✅ **能源统计分析** - 按时间、设备、类型统计汇总
- ✅ **碳排放报告** - 生成碳排放汇总报告
- ✅ **设备分类管理** - 支持多种设备类别

## API 使用

### 1. 保存能源数据

**接口：** `POST /energy/data`

**请求体：**

```json
{
  "device_id": 1,
  "energy_type": "water",
  "consumption": 15.5,       // 消耗量（必填）
  "flow_rate": 2.3,          // 瞬时流量（可选）
  "timestamp": "2024-01-24T12:00:00",  // 可选，默认当前时间
  
  // 电力专用字段
  "voltage": 220.0,          // 电压（可选）
  "current": 10.5,           // 电流（可选）
  "power_factor": 0.95,      // 功率因数（可选）
  
  // 水/气专用字段
  "pressure": 0.3,           // 压力（可选）
  "temperature": 18.5,       // 温度（可选）
  
  // 热力专用字段
  "supply_temp": 80.0,       // 供水温度（可选）
  "return_temp": 60.0,       // 回水温度（可选）
  "heat_flow": 1.5           // 热流量（可选）
}
```

**功能：**
- 保存能源数据到时序数据库
- 自动计算并保存碳排放数据
- 支持所有能源类型

### 2. 查询能源数据

**接口：** `GET /energy/data/{device_id}`

**参数：**
- `device_id` - 设备ID（必填）
- `energy_type` - 能源类型（可选）
- `start_time` - 开始时间（可选）
- `end_time` - 结束时间（可选）
- `limit` - 返回条数（默认1000）

**示例：**

```bash
GET /energy/data/1?energy_type=water&start_time=2024-01-24T00:00:00&limit=100
```

### 3. 查询碳排放数据

**接口：** `GET /energy/carbon/emissions`

**参数：**
- `device_id` - 设备ID（可选，不传则查询所有）
- `energy_type` - 能源类型（可选）
- `start_time` - 开始时间（可选）
- `end_time` - 结束时间（可选）

**响应示例：**

```json
[
  {
    "device_id": 1,
    "timestamp": "2024-01-24T12:00:00",
    "energy_type": "water",
    "energy_consumption": 15.5,
    "consumption_unit": "m³",
    "carbon_factor": 0.167,
    "carbon_emission": 2.5885,
    "scope": 2
  }
]
```

### 4. 碳排放汇总

**接口：** `GET /energy/carbon/summary`

**参数：**
- `start_time` - 开始时间（必填）
- `end_time` - 结束时间（必填）
- `device_id` - 设备ID（可选）

**响应示例：**

```json
{
  "total_carbon": 12580.45,
  "by_energy_type": {
    "electricity": {
      "carbon_emission": 8500.20,
      "energy_consumption": 14560.0,
      "unit": "kWh"
    },
    "gas": {
      "carbon_emission": 3250.15,
      "energy_consumption": 1503.5,
      "unit": "m³"
    },
    "water": {
      "carbon_emission": 830.10,
      "energy_consumption": 4972.0,
      "unit": "m³"
    }
  }
}
```

### 5. 能源统计

**接口：** `GET /energy/statistics`

**参数：**
- `energy_type` - 能源类型（必填）
- `start_time` - 开始时间（必填）
- `end_time` - 结束时间（必填）
- `device_id` - 设备ID（可选，系统级统计）
- `period_type` - 统计周期（hour/day/month/year）

**响应示例：**

```json
{
  "total_consumption": 1250.5,
  "avg_consumption": 52.1,
  "avg_flow_rate": 15.3,
  "peak_flow_rate": 25.8,
```

## 碳排放计算

### 碳排放因子

系统内置各能源类型的碳排放因子（参考国家标准）：

```bash
GET /energy/carbon/factors
```

**响应：**

```json
{
  "carbon_factors": {
    "electricity": {
      "factor": 0.5839,
      "unit": "kg CO2/kWh"
    },
    "gas": {
      "factor": 2.162,
      "unit": "kg CO2/m³"
    },
    "water": {
      "factor": 0.167,
      "unit": "kg CO2/m³"
    }
  },
  "description": "碳排放因子参考国家标准，实际使用时可根据地区调整"
}
```

### 手动计算碳排放

```bash
POST /energy/carbon/calculate?energy_type=gas&consumption=100
```

**响应：**

```json
{
  "success": true,
  "data": {
    "energy_type": "gas",
    "consumption": 100,
    "consumption_unit": "m³",
    "carbon_factor": 2.162,
    "carbon_emission": 216.2,
    "emission_unit": "kg CO2"
  }
}
```

### 自动碳排放记录

每次保存能源数据时，系统会自动：
1. 根据能源类型获取碳排放因子
2. 计算碳排放量 = 消耗量 × 碳排放因子
3. 保存到 `carbon_emission` 表
4. 标注排放范围（Scope 1/2）

## 数据统计

### 按时间段统计

```python
import requests
from datetime import datetime, timedelta

BASE_URL = "http://localhost:8088"
TOKEN = "your_jwt_token"
headers = {"Authorization": f"Bearer {TOKEN}"}

# 统计本月用水量
end_time = datetime.now()
start_time = end_time.replace(day=1, hour=0, minute=0, second=0)

response = requests.get(
    f"{BASE_URL}/energy/statistics",
    params={
        "energy_type": "water",
        "start_time": start_time.isoformat(),
        "end_time": end_time.isoformat(),
        "period_type": "month"
    },
    headers=headers
)

stats = response.json()
print(f"本月总用水量: {stats['total_consumption']} m³")
print(f"日均用水量: {stats['avg_consumption']} m³")
print(f"峰值流量: {stats['peak_flow_rate']} m³/h")
```

### 生成碳排放报告

```python
# 获取年度碳排放汇总
start_time = datetime(2024, 1, 1)
end_time = datetime(2024, 12, 31, 23, 59, 59)

response = requests.get(
    f"{BASE_URL}/energy/carbon/summary",
    params={
        "start_time": start_time.isoformat(),
        "end_time": end_time.isoformat()
    },
    headers=headers
)

summary = response.json()
print(f"年度总碳排放: {summary['total_carbon']} kg CO2")

for energy_type, data in summary['by_energy_type'].items():
    print(f"{energy_type}: {data['carbon_emission']} kg CO2")
```

### 2. 数据采集频率

建议采集频率：

| 能源类型 | 建议频率 | 说明 |
|---------|---------|------|
| 电力 | 1-5 分钟 | 高频采集，实时监控 |
| 水 | 15-30 分钟 | 中频采集 |
| 燃气 | 15-30 分钟 | 中频采集 |
| 热力 | 30-60 分钟 | 低频采集 |
| 冷气 | 15-30 分钟 | 中频采集 |

### 3. 碳排放因子更新

不同地区、不同时期的碳排放因子可能不同，建议：

- 每年更新一次碳排放因子
- 参考当地电网发布的官方数据
- 考虑可再生能源占比

### 4. 数据验证

上报数据前进行合理性检查：

```python
def validate_energy_data(energy_type, consumption, flow_rate=None):
    """验证能源数据合理性"""
    
    # 消耗量不能为负
    if consumption < 0:
        raise ValueError("消耗量不能为负")
    
    # 根据能源类型检查范围
    if energy_type == "water" and consumption > 10000:
        raise ValueError("单次用水量异常")
    
    if energy_type == "gas" and consumption > 100000:
        raise ValueError("单次用气量异常")
    
    # 流量与消耗量的合理性
    if flow_rate and flow_rate > consumption * 100:
        raise ValueError("流量与消耗量不匹配")
    
    return True
```

### 5. 定时统计任务

建议设置定时任务，每天自动生成统计报告：

```python
from apscheduler.schedulers.background import BackgroundScheduler
from datetime import datetime, timedelta

def daily_statistics():
    """每日能源统计"""
    end_time = datetime.now()
    start_time = end_time - timedelta(days=1)
    
    energy_types = ["electricity", "water", "gas", "heat"]
    
    for energy_type in energy_types:
        stats = EnergyService.calculate_statistics(
            session=session,
            device_id=None,  # 系统级
            energy_type=energy_type,
            start_time=start_time,
            end_time=end_time,
            period_type="day"
        )
        
        # 保存统计结果
        EnergyService.save_statistics(
            session=session,
            device_id=None,
            energy_type=energy_type,
            stat_time=start_time,
            period_type="day",
            stats=stats
        )

scheduler = BackgroundScheduler()
scheduler.add_job(daily_statistics, 'cron', hour=1, minute=0)
scheduler.start()
```
