# 设备维护管理功能使用指南

## 📋 功能概述

设备维护管理模块提供完整的设备维护生命周期管理，包括：

- ✅ 维护计划创建和管理
- ✅ 维护任务执行跟踪
- ✅ 维护历史记录查询
- ✅ 维护成本统计分析
- ✅ 维护提醒（即将到来、逾期）
- ✅ 多维度维护统计报表

## 🚀 快速开始

### 1. 创建维护记录

```bash
curl -X POST http://localhost:8088/maintenance/ \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "device_id": 1,
    "maintenance_type": "routine",
    "scheduled_time": "2026-02-01T10:00:00",
    "title": "月度例行维护",
    "description": "检查设备运行状态，清洁设备",
    "operator": "张三",
    "created_by": "系统管理员"
  }'
```

### 2. 开始维护

```bash
curl -X POST http://localhost:8088/maintenance/1/start \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "operator": "技术员-张三"
  }'
```

### 3. 完成维护

```bash
curl -X POST http://localhost:8088/maintenance/1/complete \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "result": "设备运行正常，已更换滤芯",
    "cost": 350.00,
    "parts_replaced": "[\"空气滤芯\", \"机油5L\"]",
    "next_maintenance_date": "2026-03-01T10:00:00"
  }'
```

### 4. 查询维护列表

```bash
# 查询所有维护记录
curl http://localhost:8088/maintenance/ \
  -H "Authorization: Bearer YOUR_TOKEN"

# 按设备ID筛选
curl "http://localhost:8088/maintenance/?device_id=1" \
  -H "Authorization: Bearer YOUR_TOKEN"

# 按状态筛选
curl "http://localhost:8088/maintenance/?status=scheduled" \
  -H "Authorization: Bearer YOUR_TOKEN"

# 按类型筛选
curl "http://localhost:8088/maintenance/?maintenance_type=repair" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## 📊 API 端点详解

### 基础操作

#### GET /maintenance/
获取维护记录列表，支持多条件筛选

**查询参数：**
- `device_id`: 设备ID
- `maintenance_type`: 维护类型
- `status`: 状态
- `start_date`: 开始日期
- `end_date`: 结束日期
- `limit`: 返回记录数（默认50，最大200）
- `offset`: 分页偏移量

**示例：**
```bash
curl "http://localhost:8088/maintenance/?device_id=1&status=completed&limit=10" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

#### GET /maintenance/{id}
获取单条维护记录详情

#### POST /maintenance/
创建新的维护记录

#### PUT /maintenance/{id}
更新维护记录

#### DELETE /maintenance/{id}
删除维护记录

### 工作流操作

#### POST /maintenance/{id}/start
开始维护（状态变更为 in_progress）

#### POST /maintenance/{id}/complete
完成维护（状态变更为 completed，自动计算时长）

#### POST /maintenance/{id}/cancel
取消维护（状态变更为 cancelled）

### 查询和统计

#### GET /maintenance/device/{device_id}/history
获取指定设备的维护历史

**示例：**
```bash
curl http://localhost:8088/maintenance/device/1/history?limit=10 \
  -H "Authorization: Bearer YOUR_TOKEN"
```

#### GET /maintenance/upcoming/list
获取即将到来的维护计划（未来7天）

**查询参数：**
- `days`: 未来天数（1-90，默认7）

**示例：**
```bash
curl "http://localhost:8088/maintenance/upcoming/list?days=30" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

#### GET /maintenance/overdue/list
获取逾期未完成的维护计划

#### GET /maintenance/statistics/summary
获取维护统计信息

**查询参数：**
- `device_id`: 设备ID（可选）
- `start_date`: 开始日期
- `end_date`: 结束日期

**返回数据：**
```json
{
  "code": 200,
  "data": {
    "total_count": 15,
    "status_breakdown": {
      "scheduled": 5,
      "in_progress": 2,
      "completed": 7,
      "cancelled": 1
    },
    "type_breakdown": {
      "routine": 8,
      "repair": 4,
      "inspection": 3
    },
    "cost_statistics": {
      "total_cost": 5250.00,
      "average_cost": 750.00,
      "max_cost": 1200.00
    },
    "duration_statistics": {
      "total_duration_minutes": 420,
      "average_duration_minutes": 60.0,

  }
}
```

### 元数据查询

#### GET /maintenance/types
获取所有支持的维护类型

#### GET /maintenance/statuses
获取所有维护状态

## 🔍 故障排查

### 问题1：无法创建维护记录
**原因：** 设备不存在或维护类型无效

**解决：**
```bash
# 检查设备是否存在
curl http://localhost:8088/devices/{device_id}

# 检查支持的维护类型
curl http://localhost:8088/maintenance/types
```

### 问题2：维护状态无法变更
**原因：** 状态转换不合法（如从 completed 变更为 in_progress）

**解决：** 按照正常流程操作
1. scheduled → start() → in_progress
2. in_progress → complete() → completed
3. scheduled → cancel() → cancelled
