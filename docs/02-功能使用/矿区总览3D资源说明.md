# 矿区总览 3D 资源说明

> 说明当前「矿区总览」3D 场景的构成、为何观感偏简单、以及如何获得/接入更合适的 3D 模型。

---

## 一、当前实现方式（为何没有「合适的 3D 建模图」）

### 1. 场景是怎么来的

- **完全由代码生成**：`frontend/src/three/mine/MineSceneGenerator.ts` 用 Three.js 的**基础几何体**（Box、Cylinder、Plane 等）拼出：
  - 能源中心、选矿车间、智能仓储、办公楼、中控中心等建筑（实为方盒 + 简单窗户/烟囱）
  - 矿坑、道路、传送带、矿卡、挖掘机等（同样是几何体组合）
- **没有使用外部 3D 模型文件**：场景里**没有**加载任何 `.glb` / `.gltf` 模型；`public/model/` 目录下目前**只有说明文档，没有模型文件**。
- **贴图与 HDR**：  
  - 代码中使用了 `textures/2k.hdr`（环境光）、`textures/mine/ground_diff.jpg`（地面）。  
  - 仓库里目前只有 `public/textures/023.hdr`，若未自行添加 2k.hdr 和地面贴图，会走回退逻辑或缺图，整体更像「色块+几何」。

因此，**并不是「没有合适的 3D 建模图」这一概念不存在**，而是当前项目里：
- **没有内置任何现成的矿区/工业 3D 模型文件**；
- 展示效果完全依赖**程序化几何 + 有限贴图**，所以看起来偏「方块化」、不够像真实矿区。

---

## 二、可选方案概览

| 方案 | 说明 | 难度 |
|------|------|------|
| **A. 使用现成 glTF/GLB 模型** | 从下方推荐渠道下载或购买矿区/工业场景或设备模型，放入 `public/model/` 并在场景中加载 | ⭐⭐ |
| **B. 自行建模后导出 GLB** | 用 Blender 等工具建矿区/设备模型，导出为 .glb 再接入前端 | ⭐⭐⭐⭐ |
| **C. 短期优化现有程序化场景** | 不引入新模型，只优化 MineSceneGenerator：更丰富几何、更多贴图、简单 LOD | ⭐⭐ |
| **D. 2D 示意图/平面图作为补充** | 保留 3D 的同时，增加「矿区平面图/示意图」视图，用 2D 表达布局与设备位置 | ⭐ |

下面重点说 **A（现成模型）** 和 **如何接入**。

## 三、哪里可以获取「合适的」矿区/工业 3D 模型

### 1. 免费可商用（注意具体 license）

- **Sketchfab**  
  - https://sketchfab.com  
  - 搜索关键词：`mining`、`industrial plant`、`factory`、`power plant`、`warehouse`  
  - 筛选 **Downloadable** + **CC 系列或 CC0**，下载时选 **glTF/GLB**。
- **Quaternius**  
  - https://quaternius.com  
  - 有免费 PBR 资源包，部分含工业/建筑类，格式多为 FBX/GLB，需看每包 license。
- **Poly Pizza**  
  - https://poly.pizza  
  - 免费 3D 资源，可筛选风格与类型，导出 glTF。
- **OpenGameArt / itch.io**  
  - 搜索 `industrial`、`mining`、`factory`、`conveyor` 等，筛选允许商用的资源，很多提供 GLB。

### 2. 付费（质量与版权更可控）

- **TurboSquid**、**CGTrader**、**Sketchfab Store**  
  - 搜索 `mining`、`mining site`、`industrial facility`、`power plant` 等，购买前确认支持 **glTF/GLB** 及商用授权。
- **国内**  
  - 如「爱给网」「模库」等 3D 模型站，搜索「矿区」「工业」「厂房」「设备」，注意格式与授权范围。

### 3. 使用时的注意点

- **格式**：优先 **.glb**（单文件、带贴图），与现有 `GLTFLoader` + `DRACOLoader` 兼容。
- **面数**：单模型建议控制在几万面以内，避免首屏卡顿；大场景可拆成多块或做 LOD。
- **尺寸与朝向**：不同来源的模型尺度、轴向不一，加载后可能要做 `scale`、`rotation`、`position` 调整。
- **版权**：务必遵守各资源的使用条款（署名、商用、修改等）。

## 四、拿到模型后如何接入项目

### 1. 放置文件

- 将 `.glb`（及如需的贴图）放到 **`frontend/public/model/`**。  
- 例如：`public/model/mine_env.glb`（整体场景）或 `public/model/equipment_pump.glb`（单设备）。

### 2. 在场景中加载

当前 `MineScene.vue` 已具备 `GLTFLoader`、`DRACOLoader`，只需在合适位置（如初始化场景时）加载模型并加入 `scene`：

```typescript
// 示例：加载矿区整体场景
gltfLoader.load(
  `${assetBase}model/mine_env.glb`,
  (gltf) => {
    const model = gltf.scene
    // 按需缩放、旋转、平移
    model.scale.setScalar(1)
    model.position.set(0, 0, 0)
    scene.add(model)
  },
  undefined,
  (e) => console.error('模型加载失败', e)
)
```

若希望「有模型就用模型，没有再用程序化场景」，可先尝试加载 `mine_env.glb`，失败或不存在时再调用现有的 `MineSceneGenerator.createCompleteScene()`。

### 3. 与现有程序化场景的关系

- **替换**：用一个大场景 .glb 替代整个 `MineSceneGenerator` 生成的场景。  
- **混合**：保留程序化建筑/道路，只把**设备**换成 .glb 模型（例如风机、泵、配电柜），在放置设备标记的位置实例化对应模型。

具体是替换还是混合，取决于你拿到的模型是「整体场景」还是「单设备/单建筑」。

## 五、短期不引入新模型时的改进方向

若暂时没有合适 3D 模型，可以从现有代码侧做小幅提升：

- **HDR 与地面贴图**：  
  - 确保有可用的 HDR（如将 `023.hdr` 作为 2k.hdr 的替代或复制一份为 2k.hdr），以及 `textures/mine/ground_diff.jpg`，减少「纯色块」感。  
- **程序化场景**：  
  - 在 `MineSceneGenerator` 中增加更多几何细节（坡道、护栏、管线轮廓）、替换/增加贴图，让建筑和地面更有层次。  
- **2D 平面图**：  
  - 在「矿区总览」中增加一个 Tab 或视图模式：用 2D 平面图/示意图展示矿区布局与设备点位，对「没有好 3D 模型」时的信息传达也有帮助。

---

## 六、总结

- **当前**：矿区总览**没有使用任何现成 3D 建模图**，完全由代码生成几何体，且 `public/model/` 下无模型文件，因此观感偏简单、不够「真实矿区」。  
- **要得到「合适的 3D 建模图」**：需要**自行准备** .glb 模型（下载或建模），放入 `public/model/`，并在场景中加载；上面给出了常见免费/付费来源与接入方式。  
- **短期**：可先通过 HDR/地面贴图、程序化细节和 2D 平面图补充，再逐步引入真实 3D 模型。

如需在 `MineScene.vue` 里加「优先加载 mine_env.glb，失败再走程序化场景」的具体代码改动，可以在此基础上再补一版实现步骤或 PR 说明。
