# 电容补偿控制器工作台五 Tab 设计

日期：2026-05-18

范围：电容补偿控制器 `capacitor_bank_controller` 的前端设备工作台信息架构。目标路由仍以设备监控入口为主，讨论范围不包含后端接口、数据库、MQTT 协议或控制语义变更。

## 1. 背景

当前电容补偿控制器存在两个主要入口：

- 监控页：`/devices/:id/monitor`，展示实时概览、三相/回路状态、趋势、谐波、告警、诊断等。
- 控制台：`/device-console/:id`，展示远程动作、手动投切、参数读写、控制日志等。

用户希望不再按“监控页 / 控制页”拆成两个页面，而是在同一个设备页面内通过 tab 切换。每个 tab 打开后应是一个完整任务页面，尽量铺满一整屏，避免依赖页面级滚轮寻找内容。

本设计是对 `2026-05-17-compensation-monitor-layout-design.md` 的进一步升级：上一版解决监控页长页面重排；本版把监控和控制合并为一个设备工作台。

## 2. 设计目标

1. 将电容补偿控制器统一成“设备工作台”，弱化单独控制台入口。
2. 使用顶部一级 tab 承载主要任务，每个 tab 是一个完整页面。
3. 页面主体以一屏为目标组织内容；表格、列表、图表明细可在组件内部滚动或局部切换。
4. 把短时高风险动作与长期参数配置分开，降低误操作风险。
5. 优先复用现有监控和控制组件，不改接口契约。

## 3. 一级 Tab

最终命名：

1. 运行监视
2. 曲线分析
3. 远程控制
4. 参数设置
5. 事件记录

### 3.1 运行监视

用途：值班和巡检的默认页，回答“设备现在是否正常”。

建议内容：

- 核心指标：功率因数、当前无功功率、投入组数、THD 或运行状态。
- 三相测量：电压、电流、有功、无功、功率因数。
- 回路摘要：投入/切除数量、分相状态、容量利用。
- 小趋势：功率因数与无功功率的短周期趋势。
- 当前异常摘要：最新告警或当前事件。

边界：

- 不放完整告警表。
- 不放参数写入。
- 不平铺所有曲线，曲线明细进入“曲线分析”。

### 3.2 曲线分析

用途：分析历史趋势、补偿效果、投切过程和电能质量。

建议内容：

- 大图表区作为主视觉。
- 页内局部切换：
  - 补偿效果
  - 三相有功 / 无功 / 功率因数
  - 三相电压 / 电流
  - 投切回放
  - 温度 / 健康度
  - 谐波趋势
  - 高次谐波频谱
- 时间范围选择仍保留在图表工具区。

边界：

- 一级 tab 不再拆出单独“谐波质量”，谐波作为曲线分析内的一类局部视图。
- 同屏只展示一个主图或一组强相关图，避免把所有趋势同时平铺。

### 3.3 远程控制

用途：执行短时控制动作，回答“我要让设备现在做什么”。

建议内容：

- 设备启停或管理状态切换。
- 控制模式切换。
- 手动投切：相别、投切动作、共补组选择。
- 远程命令动作卡片。
- 禁用原因、权限提示、离线提示。
- 最近控制结果或最近几条控制日志。

边界：

- 不放长期参数整定表单。
- 所有动作保留确认、权限和禁用原因展示。
- 高风险动作集中在本 tab，视觉上可使用风险色提示。

### 3.4 参数设置

用途：查看和修改长期控制参数，回答“设备控制策略如何配置”。

建议内容：

- 只读参数总览。
- 可写参数卡片。
- 参数写入弹窗。
- 修改原因输入。
- 参数档案不可用时的提示。
- 容量配置、分补/共补相关参数。

边界：

- 不放手动投切等即时动作。
- 参数修改和远程控制分开，避免同屏混用导致误操作。

### 3.5 事件记录

用途：追溯异常、告警和操作历史。

建议内容：

- 告警表格与处理动作。
- 事件时间线。
- 控制日志。
- 接入诊断摘要与展开详情。
- 必要时展示设备档案摘要。

边界：

- 表格可内部滚动，但不推动整页滚动。
- 告警判定仍以后端返回为准，页面不新增核心告警推导。

## 4. 布局原则

### 4.1 页面骨架

- 顶部保留统一设备头部：返回设备台账、设备名称、编号、安装位置、在线状态、当前控制模式、刷新。
- 设备头部下方放置五个一级 tab。
- tab 内容区占满剩余可视高度。
- 每个 tab 内采用“主工作区 + 侧边上下文”的布局。

### 4.2 滚动规则

- 尽量不使用页面级滚动。
- 允许组件内部滚动：
  - 告警表格
  - 操作日志
  - 事件时间线
  - 参数列表
- 允许页内局部切换：
  - 曲线分析的不同图表
  - 参数设置的参数分组
  - 事件记录的告警/日志/诊断分组

### 4.3 风险分区

- “远程控制”用于即时动作。
- “参数设置”用于长期配置。
- 两者必须分离，不放在同一个一级 tab。
- 控制类按钮继续受权限、在线状态、设备档案状态和后端能力限制。

## 5. 组件迁移建议

现有监控页组件迁移：

- `CompensationRealtimeOverview`：进入“运行监视”。
- `CompensationDetailPanel`：回路/三相部分进入“运行监视”，可按需要拆出更轻的回路摘要。
- `CompensationTrendPanel`：进入“曲线分析”。
- `HarmonicSpectrumPanel`：进入“曲线分析”的页内切换。
- `CompensationAlarmTable`：进入“事件记录”。
- `CompensationEventTimeline`：进入“运行监视”摘要或“事件记录”详情。
- `CompensationControlSummaryPanel`：可拆分到“参数设置”摘要或“事件记录”参考信息。
- `CompensationDeviceProfile` 与 `CompensationDiagnosticsCollapsible`：进入“事件记录”或作为折叠详情。

现有控制台组件迁移：

- `ControlConsoleRemotePanel`：进入“远程控制”。
- `ControlConsoleReadonlyParamsPanel`：进入“参数设置”。
- `ControlConsoleWritableParamsPanel`：进入“参数设置”。
- `ControlConsoleWriteDialog`：保留为“参数设置”的写入弹窗。
- `ControlConsoleLogPanel`：进入“事件记录”，远程控制页可保留最近结果摘要。

## 6. 非目标

- 不新增后端接口。
- 不改变现有控制命令语义。
- 不改变 MQTT payload。
- 不做全仓设备类型重命名。
- 不把 SVG 补偿设备强行套入电容补偿控制器完整五 tab。

## 7. 验收标准

- 电容补偿控制器进入设备工作台后，可看到一级 tab：运行监视、曲线分析、远程控制、参数设置、事件记录。
- 监控与控制内容在同一设备页面内完成切换，不再要求用户从监控页跳转到单独控制台才能操作。
- “远程控制”和“参数设置”分属两个 tab。
- 曲线分析通过页内切换承载补偿效果、三相曲线、投切回放、谐波趋势和高次谐波，不在一级 tab 继续拆碎。
- 事件记录集中承载告警表、事件时间线、控制日志和接入诊断。
- 页面主体无明显页面级长滚动；长表格和长日志使用组件内部滚动。
- 既有权限控制、禁用原因、确认弹窗和错误提示保留。
- 现有补偿监控和控制相关测试需随实现调整后通过。
