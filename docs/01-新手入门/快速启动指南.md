# 🚀 园区综合能源管理系统快速启动指南

> 本指南帮助您在 3 分钟内启动园区综合能源管理系统

---

## 📋 前置要求检查清单

在开始之前，请确保您的系统满足以下要求：

- [ ] **Docker Desktop 已安装** （版本 24.0+）
  - macOS: [下载地址](https://www.docker.com/products/docker-desktop/)
  - 或使用 Homebrew: `brew install --cask docker`
- [ ] **Docker Desktop 已启动** （菜单栏图标显示）
- [ ] **可用磁盘空间** （至少 2GB）
- [ ] **可用端口**：8088、5433、6379、1883

### 快速检查命令

```bash
# 检查 Docker 是否安装
docker --version

# 检查 Docker 是否运行
docker info

# 检查端口是否可用
lsof -i :8088  # 应该显示空或没有输出
```

## 🎯 方式一：一键启动（推荐）

### 第 1 步：获取项目代码

```bash
# 如果是 Git 仓库
git clone https://github.com/your-repo/MineEnergySystem.git
cd MineEnergySystem

# 如果是压缩包
unzip MineEnergySystem.zip
cd MineEnergySystem
```

### 第 2 步：执行启动脚本

```bash
# 赋予执行权限（首次需要）
chmod +x scripts/shell/*.sh bin/*.sh

# 启动所有服务
./scripts/shell/start.sh

# 需要更快启动（使用缓存）
./bin/fast_start.sh
```

### 第 3 步：等待启动完成

**首次启动**（约 3-5 分钟）：
- 下载 Docker 镜像（TimescaleDB、Redis、Mosquitto）
- 构建后端应用镜像
- 初始化数据库表结构
- 创建默认管理员账号

**后续启动**（约 30-60 秒）：
- 使用已有镜像快速启动

**启动成功标志**：
```
✅ 服务启动完成！
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📚 访问地址：
   后端 API 文档: http://localhost:8088/docs
   后端 ReDoc:    http://localhost:8088/redoc
```

### 第 4 步：访问系统

```bash
# 方式1：命令行打开浏览器
open http://localhost:8088/docs

# 方式2：手动在浏览器中访问
# http://localhost:8088/docs
```

**默认登录账号**：
- 用户名：`admin`
- 密码：`123456`

⚠️ **重要**：生产环境请立即修改默认密码！

## 🛠️ 方式二：手动启动（了解细节）

如果您想更好地控制启动过程：

### 第 1 步：创建必要目录

```bash
mkdir -p mosquitto/data mosquitto/log logs pg_data
chmod -R 755 mosquitto logs
```

### 第 2 步：检查配置文件

```bash
# 查看 Docker Compose 配置
cat docker-compose.yml

# 查看 Mosquitto 配置
cat mosquitto/config/mosquitto.conf
```

### 第 3 步：启动服务

```bash
# 构建并启动所有服务
docker compose up -d --build

# 参数说明：
# -d: 后台运行
# --build: 强制重新构建镜像
```

### 第 4 步：查看启动状态

```bash
# 查看所有容器状态
docker compose ps

# 预期输出（所有容器 STATUS 应为 Up）：
# NAME              STATUS          PORTS
# campus_backend      Up 30 seconds   0.0.0.0:8088->8088/tcp
# campus_energy_db    Up 35 seconds   0.0.0.0:5433->5432/tcp
# campus_mqtt         Up 35 seconds   0.0.0.0:1883->1883/tcp
# campus_redis      Up 35 seconds   0.0.0.0:6379->6379/tcp
```

说明：
- `docker compose logs backend` 里的 `backend` 是 Compose service 名
- `docker exec campus_backend ...` 里的 `campus_backend` 是可见容器名
- 容器内互联仍使用 `db`、`redis`、`mqtt`，数据库名和连接串已统一到当前运行时命名

### 第 5 步：查看日志（可选）

```bash
# 查看所有服务日志
docker compose logs

# 只查看后端日志
docker compose logs backend

# 实时查看日志（按 Ctrl+C 退出）
docker compose logs -f backend
```

## 🔍 验证安装

### 1. 健康检查

```bash
# 测试后端健康状态
curl http://localhost:8088/health

# 预期输出：
# {
#   "status": "healthy",
#   "version": "2.0.0",
#   "database": "connected",
#   "redis": "connected",
#   "mqtt": "connected"
# }
```

### 2. 数据库测试

```bash
# 进入数据库容器
docker exec -it campus_energy_db psql -U admin -d campus_energy

# 执行测试查询
campus_energy=# SELECT version();
campus_energy=# \dt  # 查看所有表
campus_energy=# \q   # 退出
```

### 3. Redis 测试

```bash
# 测试 Redis 连接
docker exec -it campus_redis redis-cli ping

# 预期输出：PONG
```

### 4. MQTT 测试

```bash
# 订阅 MQTT 主题（新开终端）
docker exec -it campus_mqtt mosquitto_sub -h localhost -t 'campus/#' -v

# 发布测试消息（另一个终端）
docker exec -it campus_mqtt mosquitto_pub -h localhost -t 'campus/test' -m 'Hello'

# 第一个终端应该能看到消息
```

### 5. API 文档测试

打开浏览器访问：
- Swagger UI: http://localhost:8088/docs
- ReDoc: http://localhost:8088/redoc

尝试登录接口：
1. 展开 `POST /auth/login`
2. 点击 "Try it out"
3. 输入：
   ```json
   {
     "username": "admin",
     "password": "123456"
   }
   ```
4. 点击 "Execute"
5. 应返回 JWT Token

## 💻 本地开发模式（可选）

如果需要在本地环境开发（不使用 Docker 运行后端）：

### 第 1 步：安装 Python 依赖

```bash
# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate  # macOS/Linux
# Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

### 第 2 步：启动基础服务

```bash
# 只启动数据库、Redis、MQTT
docker compose up -d db redis mqtt

# 等待服务就绪
sleep 10
docker compose ps
```

### 第 3 步：配置环境变量

```bash
# 复制环境变量模板
cp env.example .env

# 编辑 .env 文件，修改数据库连接地址
# DATABASE_URL=postgresql://admin:password123@localhost:5433/campus_energy
# REDIS_URL=redis://localhost:6379/0
# MQTT_BROKER=localhost
```

### 第 4 步：启动后端

```bash
# 确保虚拟环境已激活
source venv/bin/activate

# 启动开发服务器（支持热重载）
python run.py

# 或使用 uvicorn 直接启动
uvicorn app.main:app --host 0.0.0.0 --port 8088 --reload
```

### 第 5 步：启动前端（可选）

```bash
# 进入前端目录
cd frontend

# 安装依赖（首次需要）
npm install

# 启动开发服务器
npm run dev

# 前端访问地址：http://localhost:3000
```

```bash
docker compose logs --tail=100
```

### 重启服务

```bash
# 重启所有服务
docker compose restart

# 重启特定服务
docker compose restart backend

# 重新构建并重启
docker compose up -d --build
```

### 停止服务

```bash
# 停止所有服务（保留数据）
docker compose down

# 停止并删除数据卷（⚠️ 会删除所有数据）
docker compose down -v

# 停止特定服务
docker compose stop backend
```

```bash
# 进入后端容器
docker exec -it campus_backend bash

# 进入数据库容器
docker exec -it campus_energy_db bash

# 直接执行命令
docker exec campus_backend ls -la
```

## ❓ 启动问题排查

### 问题 1：Docker 未安装或未启动

**症状**：
```
❌ Docker 未安装
❌ Docker 未运行
```

**解决方案**：
```bash
# 安装 Docker Desktop（macOS）
brew install --cask docker

# 启动 Docker Desktop
open /Applications/Docker.app

# 等待完全启动（菜单栏图标不再闪烁）
```

### 问题 2：端口被占用

**症状**：
```
Error: Bind for 0.0.0.0:8088 failed: port is already allocated
```

**解决方案**：
```bash
# 查看端口占用
lsof -i :8088

# 方案1：停止占用进程
docker compose down
./scripts/shell/start.sh

# 方案2：修改端口映射
# 编辑 docker-compose.yml，将端口改为其他值
# 例如：8089:8088
```

### 问题 3：首次启动缓慢

**这是正常现象**，首次启动需要：
- 下载镜像（约 750MB）
- 构建后端镜像
- 初始化数据库

**后续启动会快得多**（30-60秒）

### 问题 4：服务启动失败

**检查步骤**：
```bash
# 1. 查看容器状态
docker compose ps

# 2. 查看错误日志
docker compose logs backend
docker compose logs db

# 3. 检查磁盘空间
df -h

# 4. 检查 Docker 状态
docker info
```

**解决方案**：
```bash
# 完全重置（⚠️ 会删除所有数据）
docker compose down -v
rm -rf pg_data/* mosquitto/data/* logs/*
./scripts/shell/start.sh
```

### 问题 5：数据库连接失败

**症状**：
```
sqlalchemy.exc.OperationalError: could not connect to server
```

**解决方案**：
```bash
# 等待数据库完全启动（约 10-20 秒）
sleep 20

# 测试数据库连接
docker exec -it campus_energy_db psql -U admin -d campus_energy -c "SELECT 1;"

# 重启数据库
docker compose restart db
```

## 🎯 快速测试 API

启动成功后，可以在浏览器或命令行测试 API：

### 1. 登录获取 Token

```bash
curl -X POST "http://localhost:8088/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'

# 返回示例：
# {
#   "access_token": "eyJhbGc...",
#   "token_type": "bearer"
# }
```

### 2. 获取设备列表

```bash
# 先登录获取 TOKEN
TOKEN="your-token-here"

curl -X GET "http://localhost:8088/devices" \
  -H "Authorization: Bearer $TOKEN"
```

### 3. 查看健康状态

```bash
curl http://localhost:8088/health
```
