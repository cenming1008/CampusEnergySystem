# 本地开发环境配置指南

本指南帮助你配置一个高效的本地开发环境，将 **mosquitto、timescale、redis** 放在 Docker 中运行，而 **backend** 和 **frontend** 在本地运行，方便调试。

---

## 📋 架构说明

```
┌─────────────────────────────────────────────────────────┐
│                      本地开发环境                          │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  🐳 Docker 容器（后台服务）                               │
│  ├─ TimescaleDB (localhost:5432)                        │
│  ├─ Mosquitto MQTT (localhost:1883)                     │
│  └─ Redis (localhost:6379)                              │
│                                                          │
│  💻 本地进程（可调试）                                     │
│  ├─ FastAPI Backend (localhost:8088)                    │
│  └─ Vue Frontend (localhost:5173)                       │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 🚀 快速开始

### 步骤 1：启动 Docker 服务

```bash
# 使用开发环境配置启动 Docker 服务
docker-compose -f docker-compose.dev.yml up -d

# 查看服务状态
docker-compose -f docker-compose.dev.yml ps

# 查看日志（可选）
docker-compose -f docker-compose.dev.yml logs -f
```

**预期输出：**
```
✔ Container mine_energy_db_dev   Started
✔ Container mine_mqtt_dev        Started
✔ Container ems_redis_dev        Started
```

### 步骤 2：创建本地环境配置

创建 `.env` 文件（基于项目根目录）：

```bash
# 复制环境配置模板
cp env.example .env
```

然后修改 `.env` 文件中的关键配置：

```ini
# ==================== 数据库配置 ====================
# 改为 localhost（Docker 映射到本地）
DATABASE_URL=postgresql://admin:password123@localhost:5432/mine_energy

# ==================== Redis配置 ====================
# 改为 localhost
REDIS_URL=redis://localhost:6379/0

# ==================== MQTT配置 ====================
# 改为 localhost
MQTT_BROKER=localhost
MQTT_PORT=1883

# ==================== 开发配置 ====================
DEBUG=True
LOG_LEVEL=DEBUG
RELOAD=True  # 启用热重载
```

### 步骤 3：启动后端服务

```bash
# 激活虚拟环境（如果使用虚拟环境）
source venv/bin/activate  # macOS/Linux
# 或
.\venv\Scripts\activate   # Windows

# 安装依赖（首次运行）
pip install -r requirements.txt

# 启动后端服务
python run.py

# 或使用 uvicorn 直接启动（带热重载）
uvicorn app.main:app --host 0.0.0.0 --port 8088 --reload
```

**预期输出：**
```
INFO:     Uvicorn running on http://0.0.0.0:8088 (Press CTRL+C to quit)
INFO:     Started reloader process [xxxxx] using watchfiles
INFO:     Started server process [xxxxx]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
```

### 步骤 4：启动前端服务

```bash
# 进入前端目录
cd frontend

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev
```

**预期输出：**
```
VITE v5.x.x  ready in xxx ms

➜  Local:   http://localhost:5173/
➜  Network: use --host to expose
```

## 🔧 配置详解

### Docker 服务端口映射

| 服务 | 容器端口 | 本地端口 | 连接地址 |
|------|---------|---------|----------|
| TimescaleDB | 5432 | 5432 | `localhost:5432` |
| Mosquitto MQTT | 1883 | 1883 | `localhost:1883` |
| Mosquitto WebSocket | 9001 | 9001 | `localhost:9001` |
| Redis | 6379 | 6379 | `localhost:6379` |

### 本地服务端口

| 服务 | 端口 | 访问地址 |
|------|------|----------|
| Backend API | 8088 | http://localhost:8088 |
| Backend Docs | 8088 | http://localhost:8088/docs |
| Frontend | 5173 | http://localhost:5173 |

## 📝 常用操作

### Docker 服务管理

```bash
# 启动服务
docker-compose -f docker-compose.dev.yml up -d

# 停止服务
docker-compose -f docker-compose.dev.yml stop

# 停止并删除容器（保留数据）
docker-compose -f docker-compose.dev.yml down

# 停止并删除容器和数据卷（⚠️ 慎用）
docker-compose -f docker-compose.dev.yml down -v

# 查看日志
docker-compose -f docker-compose.dev.yml logs -f [service_name]

# 重启某个服务
docker-compose -f docker-compose.dev.yml restart [service_name]
```

### 健康检查

```bash
# 检查 Docker 服务健康状态
docker-compose -f docker-compose.dev.yml ps

# 测试数据库连接
psql -h localhost -p 5432 -U admin -d mine_energy

# 测试 Redis 连接
redis-cli -h localhost -p 6379 ping

# 测试 MQTT 连接
mosquitto_sub -h localhost -p 1883 -t 'test' -v

# 测试后端 API
curl http://localhost:8088/health
```

### 数据库操作

```bash
# 进入数据库容器
docker exec -it mine_energy_db_dev psql -U admin -d mine_energy

# 重建数据库（⚠️ 会清空数据）
python scripts/python/rebuild_database.py

# 创建管理员用户
python scripts/python/create_admin.py
```

## 🐛 调试技巧

### Backend 调试

1. **使用 IDE 调试器**
   - VSCode: 配置 `.vscode/launch.json`
   - PyCharm: 直接运行 `run.py` 并设置断点

2. **查看日志**
   ```bash
   tail -f logs/app.log
   ```

3. **热重载**
   - 修改代码后自动重启（需要 `RELOAD=True`）

### Frontend 调试

1. **浏览器开发者工具**
   - Chrome DevTools (F12)
   - Vue DevTools 浏览器插件

2. **查看网络请求**
   - 检查 API 调用
   - 查看 WebSocket 连接

### Docker 服务调试

```bash
# 查看容器日志
docker logs mine_energy_db_dev
docker logs mine_mqtt_dev
docker logs ems_redis_dev

# 进入容器
docker exec -it mine_energy_db_dev bash
docker exec -it ems_redis_dev redis-cli
```

## ❓ 常见问题

### 1. 端口冲突

**问题：** 启动 Docker 时提示端口已被占用

**解决：**
```bash
# 查看端口占用
lsof -i :5432  # TimescaleDB
lsof -i :6379  # Redis
lsof -i :1883  # MQTT

# 关闭占用端口的进程或修改 docker-compose.dev.yml 中的端口映射
```

### 2. 数据库连接失败

**问题：** Backend 启动时无法连接数据库

**解决：**
```bash
# 1. 检查 Docker 服务是否运行
docker-compose -f docker-compose.dev.yml ps

# 2. 检查数据库健康状态
docker exec mine_energy_db_dev pg_isready -U admin

# 3. 检查 .env 配置
# 确保 DATABASE_URL=postgresql://admin:password123@localhost:5432/mine_energy
```

### 3. MQTT 连接问题

**问题：** Backend 无法连接到 MQTT

**解决：**
```bash
# 1. 检查 Mosquitto 配置
cat mosquitto/config/mosquitto.conf

# 2. 测试 MQTT 连接
mosquitto_sub -h localhost -p 1883 -t '#' -v

# 3. 查看 MQTT 日志
docker logs mine_mqtt_dev
```

### 4. 前端无法访问后端

**问题：** 前端调用 API 报 CORS 错误

**解决：**
- 检查 `.env` 中的 `CORS_ORIGINS` 配置
- 确保包含前端地址：`["http://localhost:5173"]`
