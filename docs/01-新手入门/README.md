## 🚀 快速开始（3步）

### Step 1: 启动系统

```bash
# 启动所有服务（推荐）
./scripts/shell/start.sh

# 需要更快启动（使用缓存）
./bin/fast_start.sh
```

### Step 2: 验证启动

```bash
# 访问 API 文档
open http://localhost:8088/docs

# 或使用命令行测试
curl http://localhost:8088/health
```

### Step 3: 登录测试

```
默认账号：admin
默认密码：123456
```

## 🔍 常见启动问题

### 问题1：Docker 未启动

```bash
# macOS：启动 Docker Desktop
open /Applications/Docker.app

# 验证 Docker 运行
docker info
```

### 问题2：端口被占用

```bash
# 查看端口占用
lsof -i :8088

# 停止占用进程
docker compose down
```

### 问题3：启动很慢

**原因**：首次启动需要下载镜像（约750MB）

**后续启动会很快**（30-60秒）
