## 📋 重建脚本详解

### 脚本功能

`rebuild_database.py` 会执行以下操作：

```
1. 删除所有表 🗑️
   ├─ 可选：保留用户数据 (--keep-users)
   └─ 安全：需要 --confirm 确认

2. 创建所有表 🔨
   ├─ Device (设备表)
   ├─ EnergyData (能源数据表 - 时序)
   ├─ CarbonEmission (碳排放表 - 时序)
   ├─ EnergyStatistics (能源统计表)
   ├─ Alarm (报警表)
   ├─ User (用户表)
   └─ Prediction (预测表)

3. 创建默认用户 👤
   └─ admin / 123456

4. 创建演示数据（可选） 📊
   ├─ 7 个不同类型的设备
   └─ 每个设备 5 条历史数据
```

### 参数说明

| 参数 | 说明 | 必需 |
|-----|------|------|
| `--confirm` | 确认执行（防止误操作） | ✅ 是 |
| `--keep-users` | 保留用户表数据 | ❌ 否 |
| `--demo-data` | 创建演示数据 | ❌ 否 |

### 使用示例

```bash
# 示例 1: 完全重建（包含演示数据）
python scripts/python/rebuild_database.py --confirm --demo-data

# 示例 2: 重建但保留用户
python scripts/python/rebuild_database.py --confirm --keep-users

# 示例 3: 完全空白的数据库
python scripts/python/rebuild_database.py --confirm
```

## 🛠️ 故障排查

### 问题 1: 命令执行失败

**错误**: `必须使用 --confirm 参数确认执行`

**解决**: 添加 `--confirm` 参数
```bash
python scripts/python/rebuild_database.py --confirm
```

### 问题 2: 数据库连接失败

**检查**:
```bash
# 检查 PostgreSQL 是否运行
docker ps | grep postgres

# 检查环境变量
cat .env | grep DATABASE_URL
```

**解决**:
```bash
# 重启数据库
docker-compose restart timescaledb

# 或重启所有服务
docker-compose restart
```

### 问题 3: 表已存在

**错误**: `Table 'device' already exists`

**原因**: 数据库中已有表

**解决**: 使用重建脚本会自动处理（先删除再创建）

### 问题 4: 导入错误

**错误**: `ModuleNotFoundError: No module named 'app'`

**解决**: 确保在项目根目录执行
```bash
cd /Users/todo/MineEnergySystem
python scripts/python/rebuild_database.py --confirm
```

## ⚠️ 注意事项

### 生产环境部署

1. **修改默认密码**
   ```bash
   # 登录后立即修改 admin 密码
   curl -X POST http://localhost:8088/auth/change-password \
     -H "Authorization: Bearer YOUR_TOKEN" \
     -d '{"new_password": "strong_password"}'
   ```

2. **配置环境变量**
   ```bash
   # 复制示例配置
   cp env.example .env
   
   # 编辑配置
   vim .env
   
   # 修改以下配置：
   # - DATABASE_URL (数据库地址)
   # - SECRET_KEY (随机生成)
   # - CORS_ORIGINS (允许的前端域名)
   ```

3. **备份数据库**
   ```bash
   # 定期备份
   docker exec mine_timescaledb pg_dump -U postgres mine_energy > backup.sql
   ```
