## 快速选择：我应该用哪种方式？

| 需求 | 推荐方式 | 原因 |
|------|---------|------|
| 快速体验系统 | 方式1（Docker） | 一键启动，无需配置 |
| 正常使用 | 方式1（Docker） | 稳定可靠，易于维护 |

## 方式1：Docker 快速启动（推荐）

### 前置要求

- ✅ Docker Desktop 24.0+ ([下载地址](https://www.docker.com/products/docker-desktop/))
- ✅ 可用端口：8088、5433、6379、1883
- ✅ 可用磁盘空间：至少 2GB

### 快速检查

```bash
# 检查 Docker 是否安装并运行
docker --version
docker info

# 检查端口是否可用
lsof -i :8088
lsof -i :5433
```

### 一键启动

```bash
# 克隆项目（如果还没有）
git clone <your-repo-url>
cd MineEnergySystem

# 启动所有服务
./scripts/shell/start.sh

# 需要更快启动（使用缓存）
./bin/fast_start.sh

# 或者使用 Docker Compose 直接启动
docker compose up -d --build
```

### 访问系统

```bash
# 后端 API 文档
open http://localhost:8088/docs

# 默认账号
# 用户名：admin
# 密码：123456
```

### 验证服务

```bash
# 查看所有容器状态
docker compose ps

# 测试后端健康状态
curl http://localhost:8088/health

# 查看日志
docker compose logs backend
```

**详细启动教程**：请查看 [快速启动指南.md](./快速启动指南.md)

## 方式2：本地开发环境

如果需要在本地开发（不使用 Docker 运行后端）：

### 第 1 步：安装系统依赖

#### macOS

```bash
# 安装 Homebrew（如果没有）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 PostgreSQL（可选，也可以用 Docker）
brew install postgresql@14

# 安装 Redis（可选）
brew install redis

# 安装 MQTT（可选）
brew install mosquitto
```

#### Linux (Ubuntu/Debian)

```bash
# 更新包列表
sudo apt update

# 安装 Python
sudo apt install python3 python3-pip python3-venv

# 安装 PostgreSQL（可选）
sudo apt install postgresql-14

# 安装 Redis（可选）
sudo apt install redis-server

# 安装 MQTT（可选）
sudo apt install mosquitto mosquitto-clients
```

### 第 2 步：创建 Python 虚拟环境

```bash
# 进入项目目录
cd MineEnergySystem

# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate  # macOS/Linux
# Windows: venv\Scripts\activate

# 验证虚拟环境
which python  # 应该指向 venv/bin/python
python --version
```

### 第 3 步：安装 Python 依赖

```bash
# 确保虚拟环境已激活
source venv/bin/activate

# 升级 pip
python -m pip install --upgrade pip

# 安装项目依赖
pip install -r requirements.txt

# 验证安装
python -c "import fastapi; print('FastAPI:', fastapi.__version__)"
python -c "import sqlmodel; print('SQLModel OK')"
```

如果安装遇到问题，请查看下面的 [Python 环境配置详解](#python-环境配置详解)。

### 第 4 步：启动基础服务

推荐使用 Docker 启动数据库等服务：

```bash
# 只启动数据库、Redis、MQTT（不启动后端）
docker compose up -d db redis mqtt

# 等待服务就绪
sleep 15

# 验证服务状态
docker compose ps
```

### 第 5 步：配置环境变量

```bash
# 复制环境变量模板
cp env.example .env

# 编辑 .env 文件
nano .env

# 修改以下配置（连接 Docker 服务）：
# DATABASE_URL=postgresql://admin:password123@localhost:5433/mine_energy
# REDIS_URL=redis://localhost:6379/0
# MQTT_BROKER=localhost
# MQTT_PORT=1883
```

### 第 6 步：启动后端服务

```bash
# 确保虚拟环境已激活
source venv/bin/activate

# 启动后端（支持热重载）
python run.py

# 或使用 uvicorn
uvicorn app.main:app --host 0.0.0.0 --port 8088 --reload
```

### 第 7 步：启动前端（可选）

```bash
# 新开一个终端
cd frontend

# 安装依赖（首次需要）
npm install

# 启动开发服务器
npm run dev

# 访问：http://localhost:5173
```

## Python 环境配置详解

### macOS 上的 Python 命令

在 macOS 上，需要注意：
- ✅ 使用 `python3` 而不是 `python`
- ✅ 使用 `pip3` 而不是 `pip`
- ✅ 或使用 `python3 -m pip`（最可靠）

### 安装依赖的三种方法

#### 方法1：使用虚拟环境（推荐 ⭐）

```bash
# 1. 进入项目目录
cd /Users/todo/MineEnergySystem

# 2. 激活虚拟环境
source venv/bin/activate

# 3. 安装依赖（现在可以使用 pip 了）
pip install -r requirements.txt

# 提示：激活后命令提示符会显示 (venv)
```

#### 方法2：使用安装脚本

```bash
# 使用项目提供的安装脚本
./scripts/install_dependencies.sh
```

#### 方法3：直接使用 python -m pip

```bash
# 不激活虚拟环境，使用模块方式
python3 -m pip install -r requirements.txt
```

### 虚拟环境管理

```bash
# 激活虚拟环境
source venv/bin/activate

# 激活后可以使用简短命令
python --version  # 不需要 python3
pip --version     # 不需要 pip3

# 退出虚拟环境
deactivate

# 重新创建虚拟环境（如果损坏）
rm -rf venv
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### TensorFlow 安装（LSTM 功能需要）

TensorFlow 较大，安装可能需要时间：

```bash
# 使用国内镜像加速
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple tensorflow scikit-learn

# 或者单独安装
pip install tensorflow>=2.13.0
pip install scikit-learn>=1.3.0
```

### 验证安装

```bash
# 激活虚拟环境
source venv/bin/activate

# 检查关键包
python -c "import fastapi; print('✓ FastAPI 已安装')"
python -c "import sqlmodel; print('✓ SQLModel 已安装')"
python -c "import tensorflow; print('✓ TensorFlow 已安装')"  # 可选
python -c "import sklearn; print('✓ scikit-learn 已安装')"    # 可选
```

## 常见问题

### 问题 1：command not found: pip

**原因**：macOS 默认没有 `pip` 命令，只有 `pip3`

**解决**：
```bash
# 方法1：使用 pip3
pip3 install -r requirements.txt

# 方法2：激活虚拟环境后使用 pip
source venv/bin/activate
pip install -r requirements.txt

# 方法3：使用模块方式
python3 -m pip install -r requirements.txt
```

### 问题 2：虚拟环境激活失败

**错误**：`source: no such file or directory`

**解决**：
```bash
# 确保在项目根目录
cd /Users/todo/MineEnergySystem

# 使用完整路径
source ./venv/bin/activate

# 或使用点号
. venv/bin/activate
```

### 问题 3：权限错误

**错误**：`Permission denied` 或 `Could not install packages`

**解决**：
```bash
# 不要使用 sudo！
# 使用虚拟环境或 --user 标志
pip3 install --user -r requirements.txt
```

### 问题 4：TensorFlow 安装失败

**原因**：TensorFlow 较大，可能网络超时

**解决**：
```bash
# 使用国内镜像
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple tensorflow

# 或分步安装
pip install numpy
pip install tensorflow
```

### 问题 5：Docker 端口被占用

**错误**：`Bind for 0.0.0.0:8088 failed: port is already allocated`

**解决**：
```bash
# 查看端口占用
lsof -i :8088

# 停止占用进程
kill <PID>

# 或修改 docker-compose.yml 中的端口映射
# 例如：8089:8088
```

### 问题 6：数据库连接失败

**症状**：
```
sqlalchemy.exc.OperationalError: could not connect to server
```

**解决**：
```bash
# 等待数据库完全启动（约 10-20 秒）
sleep 20

# 测试数据库连接
docker exec -it mine_energy_db psql -U admin -d mine_energy -c "SELECT 1;"

# 重启数据库
docker compose restart db
```

## 💡 推荐工作流程

### 日常开发

```bash
# 1. 进入项目目录
cd /Users/todo/MineEnergySystem

# 2. 激活虚拟环境
source venv/bin/activate

# 3. 确保 Docker 服务运行
docker compose ps

cd frontend && npm run dev

deactivate
```

```bash
# 激活虚拟环境
source venv/bin/activate

# 安装新包
pip install 包名

# 更新 requirements.txt
pip freeze > requirements.txt
```
