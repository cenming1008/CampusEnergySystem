# PLAN-20260403-documentation-and-entrypoint-convergence

> 状态：已启用，待文档实现 | 负责人：规范线程 | 更新时间：2026-04-03

---

## 背景

验收线程已确认上一主题 `测试质量门槛与覆盖率收敛专题` 达到阶段完成并允许退出主区，但当前 `docs/plans/current-status.md` 与 `docs/plans/handoff.md` 仍服务测试专题，主区入口已经和当前真实执行重点脱节。

当前已确认出现新一轮“文档与代码漂移”，且不属于测试专题。漂移至少包括以下五类：

- 主入口误导
- 主区主题漂移
- 架构说明过时
- 部署/命令说明过时
- 健康检查/监控访问说明滞后

本轮核心风险不是“文档没写完”，而是高频入口文档、主区文档与当前真实代码入口不一致，持续误导线程接棒、部署执行与日常运维。

本轮主题焦点明确为“入口口径收敛”，不是品牌迁移第二轮，也不是架构或部署体系重写。

## 目标

- 统一主入口、主区与高频执行文档的当前主题表达。
- 让 `README.md`、主区文档与直接相关架构/部署/监控访问说明对齐当前真实入口。
- 为文档实现线程提供清晰、可执行、可验收的最小治理边界。

## 非目标

- 不改代码实现。
- 不做全仓 rename。
- 不改数据库名、容器名、schema 名。
- 不改 MQTT topic、MQTT 用户名、Redis key、环境变量键名。
- 不改 Prometheus/Grafana/告警契约。
- 不动 `docs/archive/` 与 `docs/plans/daily/` 历史材料。
- 不做架构重构、部署体系重写、安全体系改造。
- 不把“入口口径收敛”扩大为命名迁移第二轮。
- 不把“架构说明过时”扩大为架构重构。
- 不把“部署/命令说明过时”扩大为部署体系重写。
- 不把“监控访问说明滞后”扩大为观测体系重建或安全体系改造。
- 不顺手修其他无关页面、脚本、接口或运行时配置。

## 范围

第一批允许范围仅限：

- `README.md`
- `docs/plans/current-status.md`
- `docs/plans/handoff.md`
- `docs/plans/PLAN-20260403-documentation-and-entrypoint-convergence.md`
- 与当前真实入口直接相关的架构/部署/监控访问说明文档

第一批允许处理的问题类型仅限：

- 主入口误导
- 主区主题漂移
- 架构说明过时
- 部署/命令说明过时
- 健康检查/监控访问说明滞后

补充边界：

- “与当前真实入口直接相关”仅指线程启动、部署执行、健康检查、监控访问时会直接被使用的高频入口文档。
- 不属于高频入口、不直接服务当前执行链路的文档，不默认进入第一批。

## 实施步骤

1. 规范线程锁定新主题名称、执行边界、冻结项与验收口径。
2. 主区正式从测试专题切换到 `文档与代码入口口径收敛专题`，避免双主题残留。
3. 文档实现线程只在第一批允许范围内修正文档入口口径，以当前真实入口为唯一对齐标准。
4. 验收线程核对文档与真实入口是否一致，并确认本轮没有越界扩张到代码、运行时契约或体系改造。

## 风险与回滚

### 风险

- 若主区切换不彻底，会形成“测试专题已结束但主区仍留旧态”的伪双主题状态。
- 若冻结边界没有写死，文档实现线程很容易滑向全仓 rename、运行时标识迁移或脚本/部署改造。
- 若“与真实入口直接相关”的定义过宽，第一批范围会膨胀成整仓文档清理。
- 若为了让文档成立而反向修改代码，会把当前纯规范/文档主题错误升级成实现主题。
- 若把监控访问说明滞后误判为监控体系缺陷，容易越界到 Prometheus/Grafana/告警契约调整。

### 回滚与收缩边界

- 若发现某条文档必须依赖代码或运行时契约变更才能成立，立即停止该点并回规范/探索，不得顺手扩张。
- 若发现某项修正超出第一批允许范围，应从本轮剥离并标记为后续专题，不在本 PLAN 内继续推进。
- 若主区文档与实际入口认知再次分裂，应优先收缩到 `README.md`、`current-status.md`、`handoff.md` 三个主入口重新对齐，再决定是否纳入更多高频文档。

## 验收标准

- 新 PLAN、`docs/plans/current-status.md`、`docs/plans/handoff.md` 对当前主主题的表述一致。
- `README.md` 与直接相关的架构/部署/监控访问说明不再误导当前主线、执行入口或监控访问方式。
- 本轮改动严格停留在文档治理层，没有触碰冻结的代码实现或运行时契约。
- 主区在任意时刻只服务一个当前主主题，不再保留测试专题的大段过程性状态块。
- 下一棒路径清晰固定为：`规范 -> 文档实现线程 -> 验收`
