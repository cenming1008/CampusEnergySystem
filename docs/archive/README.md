# 文档归档区

> 本目录用于存放已下线的历史文档、已完成计划、已合并来源文档和待人工确认后再删除的候选文档。

---

## 目录说明

- `root/`：根目录迁入的历史文档
- `plans/`：已完成计划与专题分析
- `功能使用/`、`开发与部署/`、`架构与设计/`、`故障排查/`：已归档的主题文档
- `history/`：原 `docs/06-历史记录/` 的整体归档内容
- `merged/`：内容已并入主文档，不再作为独立入口维护的源文档
- `pending-delete/`：审计判定为删除候选，但仍保留待人工确认的文档

---

## 使用原则

1. 归档区文档默认不再进入主导航
2. 归档区文档可以保留历史背景，但不应继续作为当前操作入口
3. 若某份归档文档重新恢复维护，应先迁回对应主题目录，再更新主索引
