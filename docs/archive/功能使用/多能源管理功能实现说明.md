### 2. 多能源管理主页面 (`frontend/src/views/EnergyManagement.vue`)

**核心功能：**

#### 2.1 能源类型切换
- 支持6种能源类型：电力、水、燃气、热力、冷气、蒸汽
- 实时显示每种能源的总消耗量
- 点击卡片切换查看不同能源类型的详细数据

#### 2.2 统计数据展示
- 总消耗量
- 平均消耗量
- 峰值流量
- 数据条数

#### 2.3 数据可视化
三个主要图表：
1. **消耗趋势图**：显示当前选中能源类型的消耗趋势
2. **多能源对比图**：饼图展示不同能源类型的消耗占比
3. **碳排放统计图**：柱状图展示各能源类型的碳排放量

#### 2.4 碳排放计算器
- 选择能源类型
- 输入消耗量
- 自动计算碳排放量
- 显示详细计算结果（消耗量、碳排放因子、碳排放量）

#### 2.5 时间范围筛选
- 默认显示最近7天数据
- 支持自定义时间范围
- 实时刷新数据

## 🚀 使用说明

### 1. 启动前端
```bash
cd frontend
npm install  # 首次运行需要安装依赖
npm run dev
```

### 2. 启动后端
```bash
python run.py
```

### 3. 访问页面
1. 登录系统：`http://localhost:5173/login`
2. 在侧边栏点击"能源管理" → "多能源管理"
3. 或直接访问：`http://localhost:5173/energy`

### 4. 使用功能

#### 查看能源消耗
1. 在顶部选择时间范围（默认最近7天）
2. 点击不同的能源类型卡片切换查看
3. 查看统计卡片了解详细数据
4. 观察图表了解趋势和对比

#### 使用碳排放计算器
1. 在右侧"碳排放计算器"面板
2. 选择能源类型
3. 输入消耗量
4. 点击"计算碳排放"
5. 查看计算结果

## 📝 注意事项

### 1. 数据依赖
- 需要后端 `/energy` API 正常运行
- 需要数据库中有能源数据（`energydata` 表）
- 建议先运行模拟器生成测试数据

### 2. 图表渲染
- 图表需要一定的数据量才能显示
- 如果数据为空，图表会显示为空
- 建议时间范围至少选择1天以上

### 3. 性能优化
- 大量数据查询时会有加载提示
- 支持数据条数限制（默认1000条）
- 图表自动响应窗口大小变化
