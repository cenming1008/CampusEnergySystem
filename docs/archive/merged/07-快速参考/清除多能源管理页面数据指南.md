# 清除多能源管理页面数据指南

## 📋 页面数据说明

**多能源管理中心**页面展示的数据包括：

### 1. **能源消耗卡片**
- 电力消耗（kWh）
- 水消耗（m³）
- 燃气消耗（m³）
- 热力消耗（GJ）
- 冷气消耗（kWh）
- 蒸汽消耗（t）

### 2. **统计数据**
- 总消耗
- 平均消耗
- 峰值流量
- 数据条数

### 3. **图表数据**
- 电力消耗趋势图（折线图）
- 多能源消耗占比图（饼图）

---

## 🔍 数据来源

这些数据来自数据库的 **`energydata`** 表（时序数据表），通过以下API获取：

- **API端点**：`GET /energy/statistics`
- **数据表**：`energydata`
- **查询条件**：根据选择的时间范围（默认最近7天）

---

## 🗑️ 清除方法

### 方法1：使用前端清理功能（推荐）⭐

**位置**：系统设置 → 数据管理 → 数据清理

**步骤**：
1. 进入 **系统设置** 页面
2. 切换到 **数据管理** 标签页
3. 找到 **数据清理** 卡片
4. 选择清理时间范围（例如：**24小时前**）
5. 点击 **"清理 24小时前的数据"** 按钮
6. 确认警告对话框

**清除内容与注意事项**：会清除 `energydata` 等表，删除后无法恢复，详见 [数据清理功能说明](../02-功能使用/数据清理功能说明.md)。

---

### 方法2：使用SQL命令（高级用户）

**适用场景**：需要精确控制清除范围

#### 清除指定时间范围的数据

```sql
-- 进入数据库
docker exec -it mine_energy_db psql -U admin -d mine_energy

-- 清除最近7天的数据（与前端默认显示范围一致）
DELETE FROM energydata 
WHERE timestamp >= NOW() - INTERVAL '7 days';

-- 清除指定日期范围的数据（例如：2026-01-17 到 2026-01-24）
DELETE FROM energydata 
WHERE timestamp >= '2026-01-17 00:00:00' 
AND timestamp <= '2026-01-24 23:59:59';

-- 清除所有数据（⚠️ 危险操作）
DELETE FROM energydata;
```

#### 清除特定能源类型的数据

```sql
-- 只清除电力数据
DELETE FROM energydata 
WHERE energy_type = 'electricity' 
AND timestamp >= NOW() - INTERVAL '7 days';

-- 只清除水数据
DELETE FROM energydata 
WHERE energy_type = 'water' 
AND timestamp >= NOW() - INTERVAL '7 days';
```

---

### 方法3：清除特定设备的数据

**适用场景**：只想清除某个设备的数据

```sql
-- 查看设备ID
SELECT id, name FROM device;

-- 清除特定设备的数据
DELETE FROM energydata 
WHERE device_id = 1  -- 替换为实际的设备ID
AND timestamp >= NOW() - INTERVAL '7 days';
```

## 📊 清除后的效果

### 清除前
- 能源消耗卡片显示：6764.82 kWh、2727.23 m³ 等
- 统计数据显示：总消耗、平均消耗、峰值流量
- 数据条数：5063 条
- 图表显示：有数据点和趋势线

### 清除后
- 能源消耗卡片显示：**0.00** 或 **0**
- 统计数据显示：**0**
- 数据条数：**0 条**
- 图表显示：**空图表**（无数据点）

---

## ⚠️ 重要提示

### 1. **数据不可恢复**
- ❌ 删除的数据**无法恢复**
- ❌ 没有回收站功能
- ✅ **建议清理前先备份数据库**

### 2. **影响范围**
清除 `energydata` 表的数据会影响：
- ✅ **多能源管理页面**（本页面）
- ✅ **驾驶舱首页**（能源统计部分）
- ✅ **报表导出**（历史数据）
- ✅ **数据分析**（趋势分析）
- ✅ **负荷预测**（LSTM模型训练数据）

### 3. **不会影响**
以下数据**不会被清除**：
- ✅ 设备信息（Device 表）
- ✅ 用户信息（User 表）
- ✅ 报警记录（Alarm 表）
- ✅ 统计数据（EnergyStatistics 表，有独立保留策略）

---

## 🔄 清除后刷新页面

清除数据后：

1. **自动刷新**：
   - 点击页面上的 **"刷新数据"** 按钮
   - 或等待页面自动刷新（如果有自动刷新功能）

2. **手动刷新**：
   - 按 `F5` 刷新页面
   - 或点击浏览器的刷新按钮

3. **重新选择时间范围**：
   - 修改日期范围选择器
   - 选择其他时间范围查看数据

## 📝 操作示例

### 示例：清除最近7天的数据（与前端默认显示范围一致）

**步骤1**：进入系统设置
```
导航：系统设置 → 数据管理 → 数据清理
```

**步骤2**：选择清理时间
```
清理时间范围：选择 "24小时前"
（这样可以清除最近7天的数据，因为24小时前包含了7天前的数据）
```

**步骤3**：执行清理
```
点击："清理 24小时前的数据" 按钮
确认警告对话框
```

**步骤4**：刷新多能源管理页面
```
返回：多能源管理中心
点击："刷新数据" 按钮
```

**结果**：
- 所有能源消耗卡片显示 **0.00**
- 统计数据全部为 **0**
- 图表显示为空

## 🎯 推荐操作流程

### 场景1：清除测试数据

```bash
# 1. 备份数据库（可选但推荐）
docker exec mine_energy_db pg_dump -U admin mine_energy > backup_$(date +%Y%m%d).sql

# 2. 使用前端清理功能
# 系统设置 → 数据管理 → 数据清理 → 选择时间范围 → 清理

# 3. 刷新页面查看效果
# 多能源管理中心 → 刷新数据
```

### 场景2：清除特定时间范围的数据

```sql
-- 1. 进入数据库
docker exec -it mine_energy_db psql -U admin -d mine_energy

-- 2. 查看要清除的数据量
SELECT COUNT(*) FROM energydata 
WHERE timestamp >= '2026-01-17 00:00:00' 
AND timestamp <= '2026-01-24 23:59:59';

-- 3. 执行清除
DELETE FROM energydata 
WHERE timestamp >= '2026-01-17 00:00:00' 
AND timestamp <= '2026-01-24 23:59:59';

-- 4. 确认清除结果
SELECT COUNT(*) FROM energydata;
```
