### 2. EnergyData表字段不匹配导致的访问错误

**问题描述：**
多个服务层代码仍在访问 `EnergyData` 表中不存在的字段：
- `energy` 字段（应该是 `consumption`）
- `power` 字段（应该是 `flow_rate`）

**受影响文件及代码位置：**

#### 2.1 app/services/analysis_service.py
```python
# 第62-66行 - 访问了不存在的字段
"current_power": round(latest.power, 2),        # ❌ power字段不存在
"voltage": round(latest.voltage, 1),
"current": round(latest.current, 2),
"today_energy": round(today_kwh, 2),
"today_cost": round(today_cost, 2),

# 第102行 - 访问了不存在的energy字段
today_kwh = (latest.energy - first_today.energy) if first_today else 0  # ❌ energy字段不存在
```

**正确的字段应该是：**
- `latest.flow_rate` 代替 `latest.power`
- `latest.consumption` 代替 `latest.energy`

#### 2.2 app/services/fdd_service.py
```python
# 第165行 - 查询了不存在的power字段
select(EnergyData.voltage, EnergyData.current, EnergyData.power)  # ❌ power字段不存在

# 第205行 - 访问了不存在的power字段
avg_power = sum(d.power for d in data) / len(data)  # ❌ power字段不存在
```

**应该改为：**
```python
select(EnergyData.voltage, EnergyData.current, EnergyData.flow_rate)
avg_power = sum(d.flow_rate for d in data) / len(data)
```

#### 2.3 app/services/mqtt_worker.py
```python
# 第141-144行 - 广播消息时访问了不存在的字段
"voltage": record.voltage,
"current": record.current,
"power": record.power,      # ❌ power字段不存在
"energy": record.energy,    # ❌ energy字段不存在
```

**应该改为：**
```python
"voltage": record.voltage,
"current": record.current,
"power": record.flow_rate,        # ✅ 使用flow_rate
"energy": record.consumption,     # ✅ 使用consumption
```

### 3. EnergyData表缺少必要字段

**问题描述：**
根据代码逻辑，系统需要追踪累计能耗（电表读数），但 `EnergyData` 表中：
- `consumption` 字段被用于表示"消耗量"
- 但很多代码期望有一个累计量字段（类似旧的 `energy` 字段）

**当前表定义：**
```python
# EnergyData表（tables.py第154行）
consumption: float = Field(description="消耗量（根据能源类型不同，单位不同）")
flow_rate: Optional[float] = Field(default=None, description="瞬时流量/功率")
```

**问题分析：**
- `consumption` 的描述不清晰：是累计值还是瞬时值？
- 分析服务需要计算今日消耗 = 当前读数 - 首条读数
- 这要求 `consumption` 必须是累计值（类似电表读数）

**建议：**
在 `EnergyData` 表的注释中明确说明：
```python
consumption: float = Field(description="累计消耗量/电表读数（kWh/m³/m³等）")
flow_rate: Optional[float] = Field(default=None, description="瞬时流量/功率（kW/m³/h等）")
```

或者添加两个独立字段：
```python
cumulative_consumption: float = Field(description="累计消耗量（电表读数）")
instant_consumption: float = Field(description="瞬时消耗量/功率")
```

### 6. 前端API返回类型与后端不匹配

**问题描述：**
前端 `telemetry.ts` 定义的 `DeviceData` 接口仍然使用旧的字段名：

```typescript
// frontend/src/api/telemetry.ts
export interface DeviceData {
  device_id: number
  timestamp: string
  voltage: number
  current: number
  power: number      // ❌ 后端已改为 flow_rate
  energy: number     // ❌ 后端已改为 consumption
}
```

**后端实际返回的字段（EnergyData）：**
```python
consumption: float
flow_rate: Optional[float]
voltage: Optional[float]
current: Optional[float]
```

**建议修复：**
```typescript
export interface DeviceData {
  device_id: number
  timestamp: string
  voltage: number | null
  current: number | null
  flow_rate: number | null      // 瞬时功率/流量
  consumption: number            // 累计消耗
}
```

### 9. 缺少统一的字段命名规范说明

**问题描述：**
从代码中可以看出，同一概念使用了不同的字段名：
- 瞬时功率/流量：有时叫 `power`，有时叫 `flow_rate`
- 累计消耗：有时叫 `energy`，有时叫 `consumption`

**建议：**
在 `docs/` 目录下添加一个 `字段命名规范.md` 文档，明确说明：
- 电力设备：使用 `flow_rate` 表示瞬时功率（kW）
- 水/气设备：使用 `flow_rate` 表示瞬时流量（m³/h）
- 所有设备：使用 `consumption` 表示累计消耗量（电表读数）
