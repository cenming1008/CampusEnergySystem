## 🐛 如果还是显示"网络请求失败"

### 检查1: Token是否有效

在Console中执行：
```javascript
console.log('Token:', localStorage.getItem('access_token'))
```

如果返回 `null`，说明你还没登录，请：
1. 访问 http://localhost:3000
2. 登录（admin / 123456）
3. 然后再访问多能源管理页面

### 检查2: 查看网络请求

1. 切换到 **Network** 选项卡
2. 刷新页面
3. 查找 `statistics` 请求
4. 点击查看 Response：
   - 如果是 `401 Unauthorized` → 没登录
   - 如果是 `200 OK` 但数据为空 → 数据库没数据
   - 如果是 `500 Internal Server Error` → 后端错误

## 🔍 调试命令（如果还有问题）

### 手动测试API

在Console中执行：

```javascript
// 1. 获取能源类型
fetch('http://localhost:8088/energy/types', {
  headers: {'Authorization': `Bearer ${localStorage.getItem('access_token')}`}
})
  .then(r => r.json())
  .then(d => console.log('能源类型:', d))

// 2. 获取电力统计
const now = new Date().toISOString()
const week = new Date(Date.now() - 7*24*3600*1000).toISOString()
fetch(`http://localhost:8088/energy/statistics?energy_type=electricity&start_time=${week}&end_time=${now}&period_type=day`, {
  headers: {'Authorization': `Bearer ${localStorage.getItem('access_token')}`}
})
  .then(r => r.json())
  .then(d => console.log('电力统计:', d))
```

如果这些手动请求能返回数据，说明API正常，问题在前端组件。
