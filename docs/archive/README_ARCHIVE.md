## 📖 为什么整合文档？

### 整合前的问题
1. **文档分散** - 10+ 个独立的 Markdown 文件，信息分散
2. **内容重复** - 多个文档包含相似的内容（如启动步骤）
3. **查找困难** - 用户需要在多个文档间切换
4. **维护成本高** - 更新功能时需要同步多个文档

### 整合后的优势
1. **统一入口** - 所有信息集中在一个 `README.md` 中
2. **结构清晰** - 按功能模块组织，易于导航
3. **便于维护** - 只需维护一个主文档
4. **提升体验** - 用户可以快速找到所需信息
