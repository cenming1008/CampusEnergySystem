## 📋 优化背景

### 发现的问题

在检查 `config/settings.json` 和 `app/services/alarm_service.py` 时，发现了逻辑不一致的问题：

**电流检测**：
```python
# 支持设备个性化配置 ✅
limit = dev_cfg.get("current_max", defaults.get("current_max", 45.0))
```

**电压检测**（修改前）：
```python
# 只使用默认值，不支持设备配置 ❌
v_max = defaults.get("voltage_max", 250.0)
v_min = defaults.get("voltage_min", 190.0)
```

**问题分析**：
- ❌ 逻辑不一致：电流支持个性化，电压不支持
- ❌ 缺乏灵活性：不同设备的电压要求可能不同
- ❌ 配置文件结构不完整：default 有电压配置，但设备配置中没有

| 电压等级 | 适用设备 | 配置示例 |
|---------|---------|---------|
| **220V** | 照明、小型设备 | `voltage_min: 190, voltage_max: 250` |

**阈值范围说明**：
- 一般为额定电压的 ±10%
- 例如：660V 设备 → 594V - 726V，取中间范围 570-690V

## 🔧 使用说明

### 如何为设备添加电压配置

**编辑**: `config/settings.json`

```json
{
  "device_thresholds": {
    "11": {
      "current_max": 150.0,
      "voltage_min": 340.0,    // 可选：设备特定最低电压
      "voltage_max": 400.0,    // 可选：设备特定最高电压
      "name": "新设备名称"
    }
  }
}
```

**配置规则**：
1. `voltage_min` 和 `voltage_max` 是可选的
2. 如果不配置，则使用 `default` 中的值
3. 如果配置了，则优先使用设备特定值
4. 建议根据设备额定电压 ±10% 设置阈值
