## 🔧 技术实现

### 场景生成器架构

```typescript
class MineSceneGenerator {
  - createCompleteScene()      // 创建完整场景
  - createBuildings()          // 创建建筑
  - createMinePit()            // 创建矿坑
  - createRoads()              // 创建道路
  - createIndustrialEquipment() // 创建工业设备
  - createVehicles()           // 创建车辆
  - createInfrastructure()     // 创建基础设施
}
```

### 动画系统

使用 `animatedObjects` 数组管理所有动态对象：

```typescript
animatedObjects.push({
  object: truck,
  animation: (time: number) => {
    // 自定义动画逻辑
  }
})
```

在 `animate()` 循环中统一更新所有动画。

## 🎨 视觉效果

### 材质系统

- **自发光**：窗户、太阳能板、路灯等带发光效果

### 光照系统
- 环境光 + 主光源 + 补光
- 阴影系统（PCF软阴影）
- HDR环境贴图

### 后期处理
- Bloom效果（发光）
- 色调映射（ACES Filmic）

## 📊 性能优化

1. **几何体复用**：相同形状使用相同几何体
2. **材质共享**：相同材质使用同一实例
3. **LOD系统**：可根据距离调整细节（可扩展）
4. **按需加载**：场景元素分步创建

## 🚀 使用方法

### 基本使用

场景会自动在 `MineScene.vue` 中初始化：

```typescript
sceneGenerator = new MineSceneGenerator(scene)
sceneGenerator.createCompleteScene()
```

### 访问场景组

```typescript
const buildings = sceneGenerator.getGroup('buildings')
const vehicles = sceneGenerator.getGroup('vehicles')
const equipment = sceneGenerator.getGroup('equipment')
```

### 清理场景

```typescript
sceneGenerator.dispose()
```
