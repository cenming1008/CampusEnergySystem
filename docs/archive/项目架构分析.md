# MineEnergySystem 项目架构分析文档

## 📋 项目概述

**MineEnergySystem（煤矿综合能源管理系统）** 是一个基于 FastAPI + Vue 3 的工业级能源监控系统，采用前后端分离架构，支持实时数据采集、报警监控、故障诊断和报表导出等功能。

## 🔄 程序运行框架

### 1. 启动流程

```
启动命令: python run.py
    ↓
run.py 调用 uvicorn.run("app.main:app")
    ↓
FastAPI 加载 app/main.py
    ↓
执行 lifespan() 启动阶段:
    1. init_db() - 初始化数据库表结构
    2. RedisClient.get_client() - 连接Redis
    3. start_mqtt_background() - 启动MQTT监听线程
    ↓
注册所有路由 (app.include_router)
    ↓
启动 HTTP/WebSocket 服务器 (端口8088)
    ↓
系统就绪，等待请求
```

### 2. 数据流转流程

#### 场景A: 设备数据上报（MQTT → 数据库 → WebSocket）

```
设备/模拟器
    ↓ 发送MQTT消息
    Topic: mine/telemetry
    Payload: {device_id, voltage, current, power, energy, timestamp}
MQTT Broker (Mosquitto)
    ↓ 消息路由
mqtt_worker.py (on_message回调)
    ↓ 解析JSON
    ↓ 调用 process_data()
data_processor.py (process_device_data)
    ↓ 保存到数据库
    ↓ 检查报警阈值
    ↓ 生成报警（如需要）
TimescaleDB (DeviceData表)
    ↓ 返回数据记录
mqtt_worker.py (broadcast_callback)
    ↓ 构建WebSocket消息（即：将接收到的设备遥测JSON数据封装成适合前端WebSocket消费的消息格式，常见为dict对象，包含新数据内容和设备ID等信息，方便前端解析和展示）
socket_manager.py (broadcast)
    ↓ 推送给所有连接的客户端
前端 (Vue组件)
    ↓ 实时更新界面
```

#### 场景B: 用户登录流程

```
前端 Login.vue
    ↓ POST /auth/login
    {username, password}
auth.py (login_for_access_token)
    ↓ 查询用户
Database (User表)
    ↓ 验证密码
security.py (verify_password)
    ↓ 生成JWT Token
security.py (create_access_token)
    ↓ 返回Token
前端 (存储Token到localStorage)
```

#### 场景C: 前端获取设备列表

```
前端 DeviceManager.vue
    ↓ GET /devices/
    Header: Authorization: Bearer <token>
deps.py (get_current_user)
    ↓ 验证JWT Token
    ↓ 获取用户信息
devices.py (read_devices)
    ↓ 查询数据库
Database (Device表)
    ↓ 返回设备列表
前端 (显示设备列表)
```

#### 场景D: 实时数据推送（WebSocket）

```
前端 (建立WebSocket连接)
    ws://localhost:8088/ws
main.py (websocket_endpoint)
    ↓ 接受连接
socket_manager.py (connect)
    ↓ 加入连接列表
    (等待MQTT数据...)
MQTT收到数据
    ↓ 调用 broadcast()
socket_manager.py (broadcast)
    ↓ 遍历所有连接
    ↓ 发送JSON消息
前端 (实时更新界面)
```

**功能：**
- 使用 uvicorn 启动 FastAPI 应用
- 从 `settings` 读取服务器配置（host、port、workers、reload）
- 支持开发模式（热重载）和生产模式（多进程）

**关键代码：**
```python
uvicorn.run(
    "app.main:app", 
    host=settings.host,      # 默认: 0.0.0.0
    port=settings.port,      # 默认: 8088
    reload=settings.reload,  # 开发环境: True, 生产环境: False
    workers=settings.workers # 工作进程数
)
```

## 🔐 安全机制

1. **JWT Token认证**
   - 所有需要权限的API都需要Token
   - Token有效期：5小时（可配置）

2. **密码加密**
   - 使用bcrypt哈希
   - 自动处理超过72字节的密码

3. **CORS中间件**
   - 限制允许的前端地址
   - 防止跨域攻击

4. **依赖注入权限验证**
   - 使用FastAPI的依赖注入机制
   - 统一的权限验证逻辑

## 📝 总结

MineEnergySystem 是一个**分层架构**的工业级能源管理系统：

1. **API层** - 处理HTTP请求，参数验证
2. **Service层** - 业务逻辑处理，数据加工
3. **Core层** - 基础设施（数据库、安全、WebSocket）
4. **Model层** - 数据模型定义

**数据流向：**
- **写入**: MQTT → mqtt_worker → data_processor → Database
- **读取**: Frontend → API → Database → Frontend
- **实时**: MQTT → mqtt_worker → WebSocket → Frontend

**扩展性：**
- 易于添加新的API端点
- 易于添加新的数据处理逻辑
- 易于集成新的数据源
